# Toonflow 技术栈复用决策

> 日期：2026-09-28  
> 状态：已确认  
> 决策范围：M01 项目与画布创作及其首发实施基线

## 1. 决策

Cruio 首发直接复用 Toonflow 当前 MIT 版本及其技术栈，不再将 React Flow 自研、Next.js＋React 重写或 Python 主后端作为并行首发路线。

固定评估基线：

```text
仓库：https://github.com/HBAI-Ltd/Toonflow-app
分支：master
提交：d86cce6b689916ab73f75bc4c1f42a2a7424516c
许可证：MIT
```

保留的主要技术基线包括 Vue 3、Vite、Vue Flow、TypeScript、Bun、Express 及仓库现有 workspace 组织。Cruio 是 Web SaaS，首发不要求复用 Electron 桌面封装。

## 2. 复用范围

优先保留项目与画布、节点与连接、剧本／角色／场景／道具／镜头／分镜、创作工具、模型参数、素材引用传递、生成交互、结果展示、自动保存和撤销重做等创作内核。

以下能力必须按 Cruio 已确认规则替换或补齐：

- 多用户账户、角色和资源归属；
- 用户数据隔离及后台最小权限；
- 模型目录、精确版本和供应渠道；
- 独立、可恢复的生成任务；
- 报价确认、逐任务预占、可靠交付后实结；
- 私有素材、平台素材和厂商资产；
- 任务输出、素材和作品的分离；
- 外部成交积分入账、外部退款积分扣回和负余额；
- 课程、运营、报表、安全与隐私治理；
- 普通软删除与独立永久删除／匿名化流程。

## 3. 许可证与版本规则

1. 复用、修改和分发时保留 MIT 版权及许可声明。
2. 固定提交是当前实施基线；不得仅引用会持续变化的 `master` 作为可追溯版本。
3. 第三方依赖、字体、图标、演示素材、插件和模型服务分别核验其许可和条款。
4. MIT 软件许可不自动授予 Toonflow 名称、Logo 或其他品牌标识权；产品使用 Cruio 品牌。
5. 未来引入上游更新时逐项评估和选择性合并，不自动改变 Cruio 业务规则。

## 4. 暂不采用

- 首发不进行 Vue 到 React 的全量重写；
- 首发不引入 Next.js 或 React Flow 作为第二条画布路线；
- 首发不以 Python 替换现有主后端；
- Python 仅在未来出现明确的媒体处理、超分、批处理或模型执行需求时作为独立 Worker 评估；
- 不因代码可复用而直接沿用 Toonflow 的默认管理员、单机数据、模型密钥或任务／积分语义。
