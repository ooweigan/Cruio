# 本地数据服务开发基线

> 日期：2026-09-28  
> 状态：用户已确认 PostgreSQL 开发选型，Cruio 独立数据库与用户已创建并验证；Redis 是否使用待实际需求决定。  
> 适用范围：Cruio 的本地开发与初期施工环境，不自动等同于生产部署方案。

## 决定

1. 初期使用用户本机的 PostgreSQL 作为开发数据库。项目、用户、生成任务、积分等需要可靠保存的业务事实，后续工程设计以 PostgreSQL 为持久化基础。
2. 本机 Redis 可用，但不因其存在就预设必须接入。只有出现明确的缓存、协调或异步处理需求，并验证收益和恢复边界后才使用；Redis 不代替 PostgreSQL 保存积分账本或唯一的任务事实。
3. 媒体文件／交付副本的存储位置、备份与生产环境数据服务另行确定；本决定不授权修改或清理用户现有数据库和 Redis 数据。
