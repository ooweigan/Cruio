## 1. 研究问题与证据口径

本文件只回答以下问题：

1. 火山方舟素材资产组和素材资产是什么，如何创建、查询、使用和删除；
2. 真人邀请、真人认证、同人一致性校验和接收授权怎样影响产品流程；
3. 素材预处理有哪些公开状态和失败原因；
4. 普通 URL／Base64 输入与 `asset://<asset_id>` 有何不同；
5. 账号、项目、地域、模型、权益包和授权有效期有哪些边界；
6. Toonflow 固定提交实际做了什么，哪些能力没有实现。

证据标签：

- **已核验事实**：由火山引擎官方文档、官方仓库或 Toonflow 固定提交源码直接确认。
- **源码事实**：只说明固定提交存在相应实现，不等于第三方渠道已通过目标账号验收。
- **设计建议**：根据证据对 M05 职责和数据边界的建议，不自动确认产品决策。
- **待账号实测**：公开资料不足，或依赖具体账号、项目、地域、权益、授权人和素材内容。

## 2. 先行结论

1. **自己的素材库、作品库和厂商资产库必须是三类对象。** Toonflow 的全局素材库是本地文件目录；生成结果是工作区文件；火山方舟 Asset 是归属于厂商账号／项目的受管资源。三者可以建立关联，但不能共用一个“URL”字段假装等价。
2. **普通 URL 与 vendor asset ID 语义不同。** 公网 URL／Base64 是单次请求的输入载荷；`asset://<asset_id>` 指向已经在方舟完成入库、处理和授权的资产。Asset ID 不是文件地址，资产详情返回的 12 小时 URL也不是稳定 Asset ID。
3. **真人素材不能被产品做成后台代上传。** 官方流程需要素材使用方发起邀请，真人主体登录自己的火山账号，阅读规则、完成真人认证、上传并授权；素材使用方随后还要接收。补充素材仍要做同人一致性校验。
4. **“上传成功”不等于“可用于生成”。** Assets API 公开状态为 `Processing/Active/Failed`；只有 `Active` 可用。失败可能来自人脸不一致、转码、内容限制、下载失败、类型／格式／时长／尺寸等问题。
5. **列表状态不一定等于详情可用性。** 真人录入官方指南明确提醒，一致性失败的素材也可能出现在列表，实际是否可用以详情页信息为准。
6. **资产与授权都有生命周期。** 单个 Asset 可被管理；删除 Asset Group 会级联删除组内所有资产且不可恢复。真人授权有有效期和拒绝／接收状态；高级创作权益到期还会限制新增，逾期超过官方窗口可能回收付费期资产。
7. **火山方舟资产能力存在独立开通和鉴权门槛。** Assets OpenAPI 是 `cn-beijing` 管控面、公开页使用 Access Key 签名和 `ProjectName`；生成 API 是数据面 API Key。是否能调用 Assets API 还取决于企业认证、合规评测和权益档位。
8. **Toonflow 没有火山方舟官方资产库接入。** 固定提交没有调用 `CreateAssetGroup/CreateAsset/GetAsset/ListAssets/DeleteAsset`，没有保存 Asset ID，也没有真人邀请／授权流程。
9. **Toonflow 的 APIMart 路径不能冒充火山方舟资产能力。** 它调用第三方 `/seedance2/private-avatar`，等待第三方任务并取 `asset_url`；源码没有证明结果是火山方舟 `asset://` ID，也没有提供资产持久化、复用、授权或删除管理。

## 3. 对象边界：文件、素材、厂商资产与作品

| 对象 | 主体与存储 | 稳定标识 | 主要状态 | 主要用途 | 不应承担的职责 |
|---|---|---|---|---|---|
| 平台普通素材 | 本平台用户上传或保存的图片／视频／音频文件 | 平台素材 ID／受控文件路径 | 上传、可用、处理失败、软删除等平台状态 | 预览、编辑、跨项目复用、作为生成输入 | 不自动代表厂商已登记、真人已授权或模型一定接受 |
| 平台作品 | 平台保存的创作结果及展示信息 | 作品 ID | 草稿、私有、发布、下架等 | 展示、分享、课程案例、作品集 | 不负责保存厂商授权状态或原始素材治理 |
| 厂商 Asset Group | 火山方舟账号／项目内的资产组合 | `group-...` | 类型和授权状态依场景而异 | 按真人或虚拟人像组织厂商资产 | 不等于平台文件夹；不应拿项目文件夹 ID 直接代替 |
| 厂商 Asset | 归属某个 Asset Group 的方舟受管资产 | `asset-...`，生成时写作 `asset://asset-...` | `Processing/Active/Failed` | 经厂商预处理后供 Seedance 引用 | 不等于其临时预览 URL；不等于平台素材所有权 |
| 普通生成输入 | HTTP(S) URL 或 Base64 等本次请求内容 | URL／请求内数据 | 本次可取或不可取 | 单次模型输入 | 不自动获得 Asset ID、厂商复用能力或真人授权豁免 |

**设计建议：** M05 至少要保存“平台素材 ↔ 厂商渠道 ↔ 厂商账号／项目 ↔ Asset Group ID ↔ Asset ID ↔ 厂商状态 ↔ 授权状态”的可选映射。一个平台素材可以没有厂商登记，也可以在不同渠道形成多个相互独立的 vendor asset；不得把 `asset_id` 直接写回覆盖平台素材 ID。

## 4. 火山方舟 Asset Group 与 Asset

### 4.1 创建与归属

#### 已核验事实

- 官方公开了 `CreateAssetGroup`、`CreateAsset`、`ListAssetGroups`、`ListAssets`、`GetAsset`、更新与删除等私域素材库接口；Asset Group 和 Asset 都有独立 ID。[创建素材资产组合](https://docs.volcengine.com/docs/ark/create-asset-group-api?lang=zh)、[创建素材资产](https://docs.volcengine.com/docs/ark/create-asset-api?lang=zh)、[查询素材资产组合列表](https://docs.volcengine.com/docs/ark/list-asset-groups-api?lang=zh)。查询：2026-09-28；适用：火山方舟 Assets OpenAPI `2024-01-01`。
- 列表 API 将 Asset Group 分为 `AIGC`（虚拟人像）和 `LivenessFace`（真人素材）；返回组 ID、名称、描述、项目、创建与更新时间。[查询素材资产组合列表](https://docs.volcengine.com/docs/ark/list-asset-groups-api?lang=zh)。查询：2026-09-28；适用版本同上。
- Asset 归属于 Asset Group，类型可以是 `Image/Video/Audio`；查询需传 Asset ID 和正确的 `ProjectName`。[查询素材资产详情](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh)。查询：2026-09-28；适用版本同上。
- 素材组和素材列表的翻页凭证不能跨接口、账号或项目使用，说明资源检索存在明确的账号／项目边界。[查询素材资产组合列表](https://docs.volcengine.com/docs/ark/list-asset-groups-api?lang=zh)、[查询素材资产列表](https://docs.volcengine.com/docs/ark/list-assets-api?lang=zh)。查询：2026-09-28。

#### 待账号实测

- 创建 AIGC 与 LivenessFace 组时，目标账号实际开放的请求字段、默认值和权限错误；
- 同一素材能否跨项目登记或复用，以及迁移项目时的官方支持路径；
- 创建请求超时后的幂等性、重名行为和对账方式；
- 中国区之外是否提供完全等价的 Assets OpenAPI。本轮官方 API 页面只核验到 `cn-beijing`。

### 4.2 异步预处理状态与详情

#### 已核验事实

`GetAsset` 用于确认资产是否完成预处理并可用于推理。公开状态：

| 状态 | 官方含义 | 产品可执行动作 |
|---|---|---|
| `Processing` | 正在预处理，无法使用 | 展示处理中；不得提交为可用 Asset 引用 |
| `Active` | 已处理完毕，可以使用 | 才可进入生成引用候选 |
| `Failed` | 处理失败 | 显示官方错误；允许用户修复素材后重新登记，不应继续引用 |

即使 HTTP 返回 200，也可能是 `Status=Failed`，必须读取 `Error.Code/Error.Message`。[查询素材资产详情](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh)。查询：2026-09-28；适用：Assets OpenAPI `2024-01-01`。

公开错误包括：

- `FaceMismatch`：真人脸一致性校验失败；
- `TranscodingFailed`、`DownloadFailed`；
- `ContentRestricted` 及各模态内容限制；
- `TypeMismatch`、`FormatUnsupported`、`FormatUndetectable`；
- 音轨缺失／不允许、时长、尺寸、宽高比、像素、帧率和文件大小不符合要求；
- 审核服务错误或内部错误。

详情和列表还返回 `LastInferenceTime`。官方说明它是资产最近一次被**提交到视频生成任务**的时间，无论该生成任务后来成功还是失败都会更新，并可能延迟 1–2 分钟；因此不能把它解释为“最近成功使用时间”。[查询素材资产列表](https://docs.volcengine.com/docs/ark/list-assets-api?lang=zh)。查询：2026-09-28。

详情／列表中的 `URL` 是公共可访问地址，但有效期只有 12 小时。[查询素材资产详情](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh)。查询：2026-09-28。

#### 设计建议

- 平台同步厂商状态时应保存原始状态、错误码、错误文案和最后同步时间；不要只存一个 `is_ready`。
- 平台预览 URL 应按需刷新，不应持久当作 Asset 的主键或长期下载地址。
- 用户看到的“登记成功”应至少对应 `Active`，而不是 `CreateAsset` 已返回 ID。
- `LastInferenceTime` 可用于运营参考，不能单独作为删除安全判断；平台还需要知道自己是否有运行中的生成任务正在引用该 Asset。

### 4.3 查询与筛选

官方列表支持按 Group Type、Group ID、名称和资产状态查询，支持游标分页及页码分页；Asset Group 与 Asset 都返回所属 `ProjectName`。[查询素材资产组合列表](https://docs.volcengine.com/docs/ark/list-asset-groups-api?lang=zh)、[查询素材资产列表](https://docs.volcengine.com/docs/ark/list-assets-api?lang=zh)。查询：2026-09-28；适用：Assets OpenAPI `2024-01-01`。

**设计建议：** M05 的厂商资产视图可以同步这些字段，但平台普通素材搜索不应依赖厂商列表实时可用；厂商故障不能让用户自己的文件消失。

## 5. 真人邀请、认证、上传与接收

### 5.1 官方控制台流程

#### 已核验事实

1. 素材使用方在方舟体验中心创建真人资产组，设置授权有效期、同意真人素材协议并生成邀请二维码；发起方账号须完成个人或企业认证。
2. 真人授权方扫描二维码，登录自己的火山账号，确认授权主体和用途，同意人脸信息处理规则并完成真人认证。
3. 真人授权方填写资产名称／描述并上传本人图片、视频或音频。
4. 首次真人认证形成基准图像；新增素材会与基准图像进行同人一致性校验，只有确认同一人的素材才能入库。
5. 一个真人素材组可以保存同一人的不同妆造，但不能混入不同人物；每次补充素材仍要做一致性校验。
6. 上传完成后自动授权给邀请二维码对应账号；素材使用方仍需在“待接收授权素材”中选择接收。拒绝后素材状态为“已拒绝”且不可使用。
7. 实际可用性以详情页为准，一致性不通过的素材仍可能在列表出现。

来源：[录入真人形象素材](https://docs.volcengine.com/docs/ark/upload-real-person-portrait-assets?lang=zh)、[人脸信息处理及授权规则](https://docs.volcengine.com/docs/ark/face-information-processing-and-authorization-rules?lang=zh)。查询：2026-09-28；适用：火山方舟中国区可信素材库、规则更新日期 2026-04-14。

官方进一步说明，“真人认证”验证当前操作者是自然人而不是翻拍或面具；“同人认证”把基准图像和上传素材做人脸特征比对。它**不与政府或公安身份库比对，不核验真实姓名、身份证件号，不是实人身份认证**。[人脸信息处理及授权规则](https://docs.volcengine.com/docs/ark/face-information-processing-and-authorization-rules?lang=zh)。查询：2026-09-28。

### 5.2 产品边界

#### 设计建议

- 平台只能引导、记录和展示火山方舟邀请／授权状态，不应代替真人点击同意、代替完成活体动作或把一个人的认证结果转给其他用户。
- 不保存真人认证原始人脸特征；如需保存邀请凭据，只保存业务所需的厂商标识、状态、授权主体、有效期和审计时间，并按敏感信息权限控制。
- “认证通过”不能写成“身份已核验”或“已实名”。产品文案应使用官方语义：真人认证、同人认证、授权已接收。
- 真人授权撤回、到期或拒绝后，应停止新的生成引用；历史已生成作品是否继续可用按具体授权协议和治理规则处理。

火山引擎使用规范明确禁止批量、自动化绕过真人审核，并要求按单个终端用户管理豁免，不得把某用户认证用于其他用户；撤回同意后不得继续处理或使用其人脸及肖像素材。[真人认证和同人认证技术服务使用规范](https://docs.volcengine.com/docs/ark/volcengine-usage-specification-for-real-person-and-lookalike-verification?lang=zh)。查询：2026-09-28；适用：火山引擎相关真人认证服务。

### 5.3 待账号实测

- 邀请二维码／链接是否有独立 API、可配置的有效期范围、失效与重新邀请语义；
- 控制台授权状态的完整枚举、状态变化延迟和是否可由 API 查询；
- 授权方撤回后 Asset API 的具体返回、已有 Asset ID 的失效时间和运行中任务处理方式；
- “接收”与 `Active` 的先后关系，以及拒绝后能否重新发起邀请；
- 目标业务是否允许平台员工看到真人素材预览及需要哪些控制台权限。

## 6. 生成引用：普通 URL 与 `asset://` 的区别

### 6.1 普通 URL／Base64

火山方舟视频示例通过 `image_url`、`video_url` 等内容项传入普通 HTTPS URL；官方资料也展示公网 URL／Base64 作为模型输入。[Seedance 人像素材指南中的普通参考视频示例](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)、[视频生成任务 API](https://www.volcengine.com/docs/82379/1393047?lang=zh)。查询：2026-09-28；适用：火山方舟视频生成 API。

普通 URL 的语义是“供应商在本次请求中取这个文件”。公开资料没有证明它会自动：

- 创建 Asset Group 或 Asset ID；
- 进入私域素材库；
- 获得真人授权或同人认证结果；
- 在后续请求中继续可用；
- 绕过真人素材限制。

### 6.2 Vendor Asset ID

已授权真人素材成功入库后，每个素材获得独立 Asset ID。生成请求在相同的 `<模态>_url.url` 字段中传 `asset://<asset_id>`，并按 `reference_image/reference_video/reference_audio` 等 role 使用。[Seedance 人像素材指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)、[录入真人形象素材](https://docs.volcengine.com/docs/ark/upload-real-person-portrait-assets?lang=zh)。查询：2026-09-28；适用：Seedance 2.0／2.5。

Asset ID 只用来向模型传入素材；提示词仍应使用“素材类型＋序号”引用，例如“图片1中的人物”，而不是在提示词中念出 Asset ID。[Seedance 人像素材指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)。查询：2026-09-28。

### 6.3 产品必须保留的差异

| 维度 | 普通 URL／Base64 | `asset://<asset_id>` |
|---|---|---|
| 身份 | 文件位置或请求数据 | 厂商受管资产标识 |
| 是否需要入库 | 否 | 是 |
| 是否有厂商处理状态 | 请求时校验／生成错误 | `Processing/Active/Failed` |
| 是否携带真人授权语义 | 不携带 | 仅在相应真人流程、账号和授权有效时成立 |
| 可否跨账号／项目假定复用 | 不应假定 | 更不能；必须按原厂商账号／项目绑定 |
| 生命周期 | 取决于 URL 或请求 | 取决于 Asset、授权、权益和删除状态 |
| 平台应保存 | 源素材及当时输入快照 | 渠道、账号／项目、组 ID、Asset ID、状态、授权与同步时间 |

**设计建议：** 生成提交前由能力规则决定“普通输入可用”还是“必须使用 Active vendor asset”。不能在请求失败后偷偷把普通 URL 登记为真人 Asset，也不能把厂商临时预览 URL伪装成普通长期素材地址。

## 7. 账号、项目、地域、模型与权益限制

### 7.1 地域与鉴权

- 查询日 Assets OpenAPI 示例均使用管控面 `https://ark.cn-beijing.volcengineapi.com/?Action=...&Version=2024-01-01`，并注明仅支持 Access Key 鉴权。[查询素材资产详情](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh)、[查询素材资产组合列表](https://docs.volcengine.com/docs/ark/list-asset-groups-api?lang=zh)。查询：2026-09-28。
- 火山方舟视频生成使用数据面 `https://ark.cn-beijing.volces.com/api/v3`，常用 API Key 鉴权；控制面和数据面的凭证边界不同。[Base URL 与鉴权](https://docs.volcengine.com/docs/ark/base-url-and-authentication?lang=zh)。查询：2026-09-28；页面最后更新 2026-06-23。
- Assets API 请求需要正确 `ProjectName`；跨账号／项目翻页凭证无效。项目绑定应视为厂商资产身份的一部分。

**设计建议：** M05 不应把 AK/SK 或 API Key 暴露给浏览器；这里只确定业务边界，不在本文选择技术实现。

### 7.2 模型和账号边界

- 官方真人素材方案明确面向 Seedance 2.0 和 2.5 系列；不能据此宣称其他模型也支持同一 `asset://` 资产或授权语义。[Seedance 人像素材指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)。查询：2026-09-28。
- Seedance 2.0／2.5 不支持直接上传含真人人脸的参考图／视频；官方提供“同账号近期可信模型原始产物”“预置虚拟人像”“已授权真人素材”等路径。[Seedance 人像素材指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)。查询：2026-09-28。
- “可信模型产物”只信任同一方舟账号、指定模型、原始未编辑产物，并有 30 天有效期；跨平台、跨账号、二次编辑或过期后不在该信任范围。[Seedance 人像素材指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)。查询：2026-09-28。

这类“同账号近 30 天原始产物”不是 Asset ID；M05 需要另存生成来源、供应商任务、原始性和有效截止时间，不能把它和可信素材库混成一个字段。

### 7.3 权益包与配额

官方高级创作权益说明：

- 使用前需企业实名认证、合规风险评测、协议确认和手机号校验；
- 基础权益可通过控制台录入真人，但不提供真人 Assets API 集成；Entry 及更高档位才公开支持相应 API 集成；
- 素材和素材组有配额，`CreateAsset` 有 QPM 限制；具体数值和价格会变动，本文件不作为采购报价；
- 到期 0–15 天会降级并限制新建；超过 15 天，付费订阅期创建的部分资产／组可能被删除且不可恢复，具体保留例外以官方当期规则为准。

来源：[Seedance 高级创作权益包购买说明](https://docs.volcengine.com/docs/ark/seedance-2-0-purchase-guide?lang=zh)。查询：2026-09-28；适用：查询日中国区公开权益规则。

**设计建议：** 权益档位、配额、QPM 和到期时间属于厂商账号能力快照，不应硬编码成模型能力；运营后台需要能标记“未开通／只可控制台操作／API 可用／到期受限”。

## 8. 删除、过期和授权失效

### 8.1 已核验事实

- `DeleteAssetGroup` 会批量删除组内全部 Asset，不可恢复；组内资产较多时删除可能耗时。[删除素材资产组](https://docs.volcengine.com/docs/ark/delete-asset-group-api?lang=zh)。查询：2026-09-28；适用：Assets OpenAPI `2024-01-01`。
- 对控制台创建的真人素材组，官方限制为只有授权已过期或已拒绝接收的组可删除；授权有效期内、尚未开始或已接收的素材组存在删除限制。[删除素材资产组](https://docs.volcengine.com/docs/ark/delete-asset-group-api?lang=zh)。查询：2026-09-28。
- 人像主体有删除和撤回同意的权利；真人服务规范要求客户收到撤回后停止继续处理、使用相应人脸和肖像素材。[人脸信息处理及授权规则](https://docs.volcengine.com/docs/ark/face-information-processing-and-authorization-rules?lang=zh)、[真人认证和同人认证技术服务使用规范](https://docs.volcengine.com/docs/ark/volcengine-usage-specification-for-real-person-and-lookalike-verification?lang=zh)。查询：2026-09-28。
- 权益到期可能导致新增受限和厂商资产回收；Asset 详情 URL 本身只有 12 小时有效期，但 URL 过期不等于 Asset 已删除。[权益包说明](https://docs.volcengine.com/docs/ark/seedance-2-0-purchase-guide?lang=zh)、[查询素材资产详情](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh)。查询：2026-09-28。

### 8.2 设计建议

- 平台普通素材软删除、厂商 Asset 删除、Asset Group 级联删除、真人撤回授权是四个不同动作。
- 普通用户删除平台素材时，不应默认级联删除厂商 Asset；反向亦然。需先检查运行中任务、作品引用、授权治理和操作者权限。
- 厂商删除是不可逆外部写操作，应由受控后台动作明确确认；M05 只定义业务规则，不在本轮执行。
- 厂商 Asset 失效后应停止新的生成引用，但历史生成任务、账务和授权审计记录仍需保留。

### 8.3 待账号实测

- 单个 `DeleteAsset` 对 `Processing`、`Active`、`Failed` 和运行中引用分别返回什么；
- 已提交但尚未完成的视频任务引用了随后删除／失效 Asset 时，任务是否继续、失败或保留快照；
- 授权到期、撤回、账号停用、项目删除和权益到期在 API 中分别表现为什么错误码；
- 到期回收规则对免费期、Entry、付费期前后创建资产的准确划分。

## 9. Toonflow 固定提交审查

### 9.1 本地素材库

#### 源码事实

- Toonflow 全局素材库通过 `/api/assets/list/read/save/mkdir/rename/remove` 管理本地数据目录下的文件和文件夹；保存创作输出时从工作区读取文件，再复制到全局素材目录。[素材库界面保存逻辑](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/apps/web/src/pages/workspace/panels/canvas/components/assetLibrary.vue#L219-L310)、[素材目录实现](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/apps/server/src/utils/assets/index.ts)。查询：2026-09-28；适用：固定提交。
- 图片节点上传把文件保存到工作区，并把本地相对路径写入节点输出。[图片节点上传](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/packages/nodes/imageNode/src/index.vue#L116-L133)。查询：2026-09-28。
- 生成前，服务器从工作区读取引用文件，限制为 100 MB，校验媒体类型后转换为 base64 `MediaInput` 传给 provider。[引用素材读取](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/apps/server/src/utils/media/generation.ts#L69-L79)。查询：2026-09-28。

**结论：** 这是自己的文件素材管理，不是厂商 Asset Group／Asset 管理。文件路径不携带厂商账号、项目、授权、预处理状态或 Asset ID。

### 9.2 TF-router 与秘塔 MiniMax provider

#### 源码事实

- TF-router 将本地引用转换为 data URL；若输入已经是 URL则只接受 HTTP(S)，随后把这些值写入渠道自己的生成请求。没有 `asset://` 分支和官方 Assets API 调用。[TF-router 媒体转换](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/packages/providers/src/media/tfRouter.ts#L39-L54)、[视频引用组装](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/packages/providers/src/media/tfRouter.ts#L218-L280)。查询：2026-09-28。
- 秘塔 MiniMax provider 同样只把输入转成 URL／data URL并直接放入生成 content，没有厂商资产登记。[秘塔 provider 引用处理](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/packages/providers/src/media/meta.ts#L20-L24)、[生成 content](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/packages/providers/src/media/meta.ts#L73-L105)。查询：2026-09-28。

### 9.3 APIMart provider

#### 源码事实

1. 本地图片先上传到 APIMart 自有 `/uploads/images`，返回一个普通 URL；已有 URL则直接透传。
2. Seedance **reference 模式的图片**会提交到 APIMart `/seedance2/private-avatar`；适配器每次构造一个带时间戳的新组，轮询第三方任务，最终提取 `usable_assets[].asset_url`。
3. 首帧／尾帧和普通 single-image 分支没有走这段 `private-avatar` 审核；视频／音频引用也没有对应登记实现。
4. 任务 ID 和结果 URL只存在于本次函数调用；没有保存组 ID、Asset ID、授权主体、有效期或可复用映射，也没有列举、详情、更新和删除 UI。

来源：[APIMart 上传与 Seedance 私有素材审核](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/packages/providers/src/media/apiMart.ts#L50-L114)、[APIMart 视频引用分支](https://github.com/HBAI-Ltd/Toonflow-app/blob/d86cce6b689916ab73f75bc4c1f42a2a7424516c/packages/providers/src/media/apiMart.ts#L248-L330)。查询：2026-09-28；适用：固定提交。

**证据结论：** 这只能证明 Toonflow 存在一个第三方渠道的“上传＋审核＋返回可用 URL”适配路径。源码未证明 `asset_url` 是火山方舟官方 `asset://<asset_id>`，也未证明该流程包含真人邀请、本人授权或火山方舟 Assets API。产品文档不得把它写成“已接入官方真人素材库”。

### 9.4 固定提交未发现的能力

本轮在固定提交 `apps` 与 `packages` 中检索 `asset://`、`CreateAsset`、`AssetGroup`、`asset_id` 等标识，未发现：

- 火山方舟官方 Asset Group／Asset CRUD；
- 官方 Access Key 管控面签名调用；
- vendor asset ID 的平台持久化；
- 真人邀请、真人认证、接收／拒绝／撤回授权流程；
- `Processing/Active/Failed` 的官方 Asset 状态同步；
- 厂商 Asset 复用、删除和到期处理。

这是对固定提交本轮范围的源码检索结论，不是否定第三方中转平台自身可能在服务器端另有实现。

## 10. 对 M05 职责和范围的证据性建议

### 10.1 M05 应负责

- 平台普通素材的上传、分类、搜索、预览、软删除、恢复、引用关系和权限；
- 平台作品与源素材／生成任务的关联，但作品发布状态仍由作品模块负责；
- 厂商资产登记记录：渠道、厂商账号／项目、组类型、组 ID、Asset ID、媒体类型、原始厂商状态、错误、最后同步时间；
- 真人邀请与授权状态的展示和受控操作入口，但不代替真人完成认证；
- 生成前验证 vendor asset 当前为 `Active`、授权和权益仍有效、模型支持且账号／项目匹配；
- 厂商临时预览 URL按需刷新，不把它当长期主数据；
- 厂商删除／过期／撤回后停止新的引用，同时保留历史任务和审计关联。

### 10.2 M05 不应负责

- 把 Asset 预处理任务当成视频生成任务；前者属于厂商资产登记子流程，后者仍由 M04 管理；
- 根据图片长相自行宣布“真人认证通过”或“已获肖像授权”；
- 使用蒙版或编辑规避厂商真人审核；
- 把平台普通素材删除直接解释为厂商删除；
- 把厂商素材登记成功解释为可以商用；商业使用仍受授权范围、期限、场景和相关规则约束；
- 用 APIMart 或 TF-router 的 URL 替代火山方舟官方 Asset ID，而不记录渠道差异。

### 10.3 建议的非阻塞保守假设

在账号尚未验收前，总 PRD 可以先按以下假设继续：

1. 首发平台素材管理独立可用，不依赖火山方舟 Assets API；
2. vendor asset 是可选渠道映射，只有状态 `Active` 才对生成可选；
3. 真人认证和授权由火山方舟官方界面完成，本平台先做引导、状态同步和引用；
4. 任何未知、过期、撤回、跨账号／跨项目或权限错误都阻止新的 vendor asset 引用，但不删除平台原文件；
5. 未经目标账号验收，不承诺自动登记、支持真人、审核通过或可商用。
