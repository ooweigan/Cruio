# 92 版本范围与施工工作基线

> 文档状态：V1 施工工作基线 v0.2；依据用户已确认决策，以及“未确定的按建议来”的指示采用本文件建议默认。可据此启动 V1 开发，但不代表功能已经实现、渠道已开通或获准上线；也不是开发排期、报价或人员配置。  
> 日期：2026-09-28。  
> 输入：`00` 功能模块规划、`01` 总 PRD、`03` 全局业务规则、M01–M14 分模块 PRD、`04` 非功能验收、`90` 端到端验收、`91` 一致性审查及已确认决策。  
> 原则：完整业务范围不删减；分期只决定何时开放及达到何种深度。用户直接确认的约束优先；其他分期按建议作为可调整的施工默认，不冒充用户逐项确认。实际渠道、授权、合规及质量证据仍是相应功能的开放／上线门槛，不是启动整个项目开发的前置批准。

## 1. 版本工作默认与优先级语义

| 分类 | 含义 | 进入版本的条件 |
|---|---|---|
| **必须** | 该版本核心承诺成立所必需；缺少则不开放对应产品范围 | 对应主链、权限、账务、异常与验收全部通过；硬阻断项无未解决问题 |
| **应该** | 明显改善完整度、运营可承接性或用户恢复体验；建议同版纳入 | 主链已稳定且运营负责人确认可支持；否则明确延后，不影响不相干路径 |
| **可以** | 有价值但非该版本闭环前置；用于验证后续用户价值 | 不增加未批准的资金、授权或权限风险；按验证结果择机开放 |
| **本版不做** | 本版本明确不提供；不等于从完整产品范围删除 | 只能在后续单独评审、补充证据和门槛后启用 |

版本切分工作默认：

1. **V1 首发：稳定创作与线下成交积分闭环。** 普通素材到模型生成、任务恢复、可靠交付、积分实结／释放、结果保存和异常人工处理形成闭环。
2. **V1.x 内容与学习验证：** 在 V1 质量门槛稳定后，有条件开放作品公开／案例、课程及练习画布。V1 默认不开放课程；如业务需要提前试点，另行变更范围。
3. **V2+ 交易与经营扩展：** 仅当商业规模、运营能力、合规与渠道条件充分时，另行启用 M08 平台订单／支付，再评估 M09 订单佣金、会员或老师商业化。不是当前承诺。

“P0/P1/P2”是分模块文档的优先级标记；本文件的“必须／应该／可以／本版不做”是版本范围分类。两者用途不同，不自动一一映射。

## 3. V1 首发主链及最小可用深度

```text
注册／登录与资源隔离
    → 私有素材上传／来源与授权声明
    → 经核验的模型、渠道及能力展示
    → 画布编辑与保存
    → 查看积分报价并确认
    → M07 逐任务预占
    → M04 持久任务与官方协议语义提交
    → 等待／恢复／失败／未知处理
    → 可靠转存且用户可访问
    → M07 实结；明确失败则释放，未知继续预占
    → 用户主动保存为私有作品
    → M11/M12 可核查与客服交接
```

V1 最小深度不是仅完成上图的成功路径；还必须满足断线／刷新／重启恢复、重复请求、回调重复／乱序、供应商延迟、结果链接失效、并发预占、负余额、凭据隐私和越权访问的对应验收。

## 4. 首发开放／上线门槛与阻断条件

以下是对应功能面向真实用户开放及上线的硬门槛，不是启动 V1 开发前必须全部完成的产品决策。任何一项未满足时，只阻断受影响的模块／渠道／素材或资金能力；不得为了按期开放而假设通过。无安全隔离方案时，阻断相关首发整体。

| 门槛 | 必须满足的证据／验收 | 未通过时处理 | 负责人建议 |
|---|---|---|---|
| 1. 软件许可与应用级复用 | 固定 Toonflow 提交和 MIT 声明可追溯；第三方依赖、素材、插件、商标逐项核验；改造后项目／保存／恢复／任务主链验收 | 不得以“上游是 MIT”推定全部资产可用；移除或替换未核验部分，必要时暂停相关复用 | 产品、法务／许可核验责任人、研发 |
| 2. 市场与数据处理 | 目标市场、产品服务角色、告知／同意方式及数据处理事项有责任人和结论；每条模型渠道记录地区、输入类型、公开留存／训练说明与删除能力状态 | 未知项所涉及的渠道／输入关闭或限制；不得标记“合规通过” | 产品负责人、目标市场合规责任人 |
| 3. 官方供应渠道能力 | 每个开放组合记录供应商、采购渠道、精确模型 ID／版本、地区／账号权限、官方 SDK／协议操作、参数输入、状态／结果和成本依据；格式差异的兼容层保留官方协议语义及原渠道事实 | 模型展示名不构成上线依据；只关闭未验证组合，不影响已通过组合 | 模型／渠道负责人 |
| 4. 素材与厂商资产授权 | 私有上传流程、用途告知、来源声明及素材引用边界可验收；厂商 Asset ID、账号／项目范围、登记／失效／撤回状态仅在实测渠道启用 | 普通私有素材主链可继续；未核验厂商登记入口隐藏／禁用 | 素材与授权负责人 |
| 5. 用户隔离 | 游客、用户 A/B、客服、运营及撤权角色对项目、素材、任务、作品、积分、课程、凭据和后台分别完成越权测试；未授权资源不可通过 URL／搜索／下载／通知链接访问 | 任一跨用户泄露或敏感岗位越权即阻断相关范围 | 账户／权限负责人 |
| 6. 计费与结算 | 报价确认快照与规则版本；并发任务独立预占；可靠可访问交付实结、明确失败释放、未知待核查；重复请求／回调不重结；账本正反向对平 | 任一错误扣分、未知误判或重复结算阻断生成计费路径 | M04/M07 产品负责人及财务运营 |
| 7. 外部充值与退款扣回 | 后管凭据字段、目标用户、积分数、渠道、外部单号／合同号、凭据引用、操作人／时间可追溯；截图访问受限；负余额和后续优先抵欠规则验收 | 禁止缺依据入账；不把外部退款显示为平台退款；无权操作阻断 | 后台／积分负责人 |
| 8. 任务恢复和异常可处理 | 页面关闭、刷新、重登、网络抖动、服务重启、供应商等待、未知状态、结果获取失败、重复／乱序回调均按 04/90 通过；未知待办有人负责处理 | 未知状态必须可见并保留预占；无法核查原任务的渠道不开放长任务能力 | 任务／运营负责人 |

## 5. 必需验收清单

每条都是 V1 发布门槛，而非“演示成功”的替代品；按[《04-非功能需求与验收》](./04-非功能需求与验收.md)和[《90-端到端场景与验收》](./90-端到端场景与验收.md)执行并留存结果。

1. **主链成功：** 注册→上传授权素材→画布保存→选经核验渠道→报价确认→预占→任务→可靠交付→实结→主动保存私有作品。
2. **供应商失败：** 明确拒绝／失败释放预占；用户能看安全化原因；不会额外赠分或误保存作品。
3. **未知／恢复：** 请求超时、页面关闭、断线和服务重启均查找原任务；未知状态不实结、不释放、不盲目重提。
4. **交付失败：** 上游成功但结果链接失效、下载失败、文件损坏或用户不可访问时，不判可靠交付；恢复同一结果或核实最终失败。
5. **幂等与并发：** 重复点击／请求、回调重复／乱序不形成第二供应商任务、第二预占或重复账务动作；并发任务分别占用余额。
6. **余额充足性：** 可用积分不足或预占失败时不调用供应商；画布编辑不产生任务／费用。
7. **账务正向对账：** 预占、实结／释放与 M04 状态可逐项对账；用户余额和后台账本一致。
8. **账务反向对账：** 外部退款凭据扣回、负余额、限制付费生成、后续入账填平均正确；历史不覆盖。
9. **价格版本变更：** 已确认报价和在途任务不因后续改价静默变化；新任务使用新规则报价。
10. **私有数据隔离：** 用户 A/B、游客、客服、运营及角色撤销测试覆盖页面、API 资源入口、文件下载和通知跳转；零未授权读取。
11. **素材真实性：** 普通上传不产生虚假厂商 Asset ID；跨模型／渠道／账号／项目复用重新校验；撤回后不允许新引用。
12. **作品范围：** 任务结果未主动保存时无作品；分享／公开只传递明确授权字段，不暴露源项目、私有素材、厂商 ID、秘密或任务日志。
13. **外部交易真实性：** 手工充值／退款仅记外部凭据与对应积分事实；没有 M08 平台支付／退款或 M09 平台佣金；会员入口不存在。
14. **课程边界：** V1 不向用户露出可购买／已解锁课程的假象；若经范围变更提前试点，外部凭据核验后独立授予课程权，课程权不含生成额度，老师仅访问获分配内容。
15. **通知与客服：** 通知排队／失败不等于业务失败；工单关闭不更改任务／账本；客服可转交而无权直接改源事实。
16. **许可、渠道与治理：** 固定提交、依赖／素材／品牌、模型官方能力、账号地区、目标市场、告知、授权和生成标识的上线前记录齐备；不把“公开文档存在”当作账号及法规均通过。
17. **产品质量：** 支持浏览器矩阵、基础键盘／状态可读性、画布／媒体实测负载和错误反馈达到负责人批准目标；未批准的性能数值不得对外承诺。

## 6. V1 首发非目标

- 线上商品、订单、支付、退款、订阅、会员及平台货币流；线下交易不得模拟为平台订单。
- 平台佣金余额、佣金结算／打款、多层分销；任何线下合作报酬不进入 M09。
- V1 课程目录与学习访问、课程线上销售、老师自由入驻、独立定价和分成；免费／外部授权课程默认放 V1.x，若要提前试点则变更 V1 范围。
- 批量多任务部分成功（在模块 PRD 中为 P1）；V1 不展示未启用的批量入口。
- 团队空间、多人实时协作和团队资产库。
- 未核验模型／渠道／地区／账号能力；未经授权或能力验证的厂商资产登记。
- 完整视频剪辑、超分、视频逐帧遮挡、音频去识别、人脸／身份／活体识别及任何规避审核、真人判定、身份验证、授权校验或供应商风控的工具。
- 大规模开放社区、关注／收藏等社交功能、直播、考试和证书。
- 未在所声明浏览器和负载范围验证的设备承诺、固定生成完成时间或未经测量的 SLA。
