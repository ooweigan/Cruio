本模块覆盖用户素材管理、受授权平台素材、创作中的素材组织，以及模型厂商登记资产及其资格状态。文件上传成功不代表素材拥有明确授权，也不代表厂商资产已经可用。本文不写存储实现、数据库表或 API。

## 1. 模块目标

让创作者能找到、预览、整理并在授权范围内复用自己的输入素材；让课程和运营内容可以有边界地提供平台素材；让用户及运营能看清某素材是否已在某个具体模型供应渠道登记、处理、通过、失效或需要重新登记。

成功意味着：每个素材都能说明来源、所有者、用途和授权范围；厂商资产记录能追溯到实际渠道、账户、模型、区域和供应商状态；失效或被删除的素材不会进入新任务；普通素材、作品文件、生成输出和外部 Asset ID 不会混为同一对象。

## 2. 业务边界与对象

### 2.1 三层主对象

| 对象 | 业务含义 | M05 主责内容 | 不代表什么 |
|---|---|---|---|
| 平台素材 | 用户拥有或获准使用的图片、视频、音频及必要说明；平台也可在明确授权后提供平台素材 | 来源、所有者／提供者、媒介信息、授权声明、状态和可使用范围 | 上传成功不等于权属已验证，不等于可商用、可公开或可用于任意模型 |
| 素材组织 | 对素材进行目录、集合、标签、角色／场景／道具类别、项目引用与版本整理 | 用户素材夹、素材集、标签、引用位置和重复素材提示 | 目录或“角色”标签不自动创建剧本角色业务对象，也不授予权利 |
| 厂商登记 | 同一平台素材在特定模型厂商／供应渠道下获得外部登记身份、处理状态和引用资格 | 登记申请、外部 Asset ID、适用模型／账户／地区、状态同步、失效和撤回记录 | 文件已上传、URL 可访问或同厂商其他渠道已有 ID，不代表已登记或可用 |

### 2.2 与任务输出、作品和课程的关系

- 任务输出由 M04 主责，可靠交付后仍不自动成为用户素材；用户主动选择“存为素材”时，M05 创建素材引用或新素材身份，并保留来源任务。
- 长期作品由 M06 主责。作品被选为创作输入时，M05 保存授权和引用关系，不把作品本体变成另一份公开素材。
- 课程素材由 M10 管课程关联和学习范围，底层素材来源、授权及可使用事实由 M05 主责；老师只能操作被分配课程内容。
- 厂商登记资产是平台素材的外部渠道映射。厂商端状态变化由 M05 跟踪并影响后续引用，不得更改原始平台素材及权属声明。

### 2.3 明确不负责

M05 不判定素材权属真伪，不代替法律意见，不维护模型输入能力（M03），不提交生成任务（M04），不维护用户作品公开状态（M06），不授予课程访问权（M10），不决定审核／隐私政策（M14）。

## 4. 范围与边界

素材范围包含个人输入、平台授权内容、项目组织关系和外部厂商登记映射。首发至少考虑图片、视频、音频；具体上传限制按产品运营策略发布。厂商资产入口只有在 M03 已验证实际渠道能力后才可启用。普通素材上传、项目引用和用户主动将结果转为素材，不依赖 Seedance 资产库开通才能成立。

## 5. 用户、角色与权限

| 角色 | 可以做什么 | 权限边界 |
|---|---|---|
| 普通创作者 | 上传、导入、整理、预览本人素材；声明素材来源与用途；在目标渠道支持时发起登记；管理本人厂商登记映射 | 不能查看其他用户私有素材；不能伪造授权或将不明来源声明为已授权 |
| 学员 | 在课程授权范围内查看／使用课程素材；管理本人练习素材 | 课程素材权不等于下载原文件、商用、公开或转用于其他课程 |
| 受邀老师 | 维护被分配课程的素材关联和练习材料 | 仅能访问所分配课程内容及必要素材；不得看学员无关私人素材 |
| 内容／素材运营 | 管理平台素材、授权范围、上架状态和平台素材引用 | 只处理明确授权用于平台的资产；不把后台上传视为获得版权 |
| 模型／渠道运营 | 查询渠道登记可用性、配额／失败摘要并维护 M03 配置关联 | 不默认查看原始素材或授权凭证；不得把第三方渠道状态写成官方状态 |
| 客服／安全运营 | 按工单或治理案件查看必要摘要，执行 M14 规定的限制或下架申请 | 不导出整库素材，不核验权属真实性，不修改用户原始授权事实 |

授权证明若需收集，其查看权限限于被授权的隐私／安全处理岗位；普通素材管理和模型运营只看授权状态及必要摘要。遵守 M02、M11、M14 最小权限。

## 6. 信息架构与页面

### 6.1 用户素材库

| 页面／区域 | 核心信息 | 操作 | 状态／异常 |
|---|---|---|---|
| 我的素材 | 缩略图、名称、媒介、目录、标签、来源、更新时间、授权／可用摘要 | 上传、导入、搜索、筛选、排序、新建目录／素材集 | 空库引导、处理中、失败、格式不支持、超额或网络中断 |
| 素材详情 | 预览、归属、来源、授权范围、被哪些项目引用、厂商登记列表、失效与版本记录 | 编辑元数据、收藏、重命名、管理授权声明、登记／重试、软删除 | 失效提示列出影响；不得只用颜色表达资格 |
| 上传／导入面板 | 支持媒介类型、用途与来源声明、可选标签 | 多选提交、取消未完成上传 | 显示逐文件成功／失败，不把部分失败报为全成功 |
| 素材集／角色集 | 用户自定义集合和内容关系 | 添加／移除素材、按项目／课程组织 | 删除集合不自动删除集合内素材或作品 |
| 厂商资产面板 | 实际厂商／渠道、凭证账户别名、模型／区域、登记 ID、处理／可用状态、资格／配额提示和最近同步时间 | 发起登记、查看条件、重试可恢复登记、请求撤回／删除（能力支持时） | 明确区分等待厂商处理、被拒、未知、失效、外部删除不支持 |

### 6.2 平台素材与后台管理

- 平台素材库按可用范围展示：生成可用、私人草稿可用、课程限定、公开展示或商业使用等授权标记。
- 平台素材详情可查提供者、授权范围与期限、适用模型／渠道限制、来源凭证摘要、复核／下架状态。
- 运营上架必须选择素材授权范围和可见范围；未选择用途的内容不可默认成为平台公共素材。
- 后台可查看素材／厂商登记失败队列和受影响任务摘要；M11 是操作入口，M05 保留素材事实。

## 7. 关键用户流程

### 7.1 上传并用于创作

1. 用户上传或导入文件，查看系统支持的类型和大小说明。
2. 用户选择来源声明和用途；若是本人／第三方真人或疑似敏感素材，按 M14 提示授权及目标供应商限制。
3. 平台完成文件可读性与基本内容校验后，素材进入可用或待处理状态；失败文件逐项说明原因。
4. 用户可在素材详情加入目录、标签、角色／场景／道具集合。
5. 用户在项目中引用素材；M01 展示引用，M05 继续主责该素材状态和授权范围。
6. M04 每次新提交前按当前素材、授权及 M03 能力重新校验。引用不能绕过失效或撤回状态。

### 7.2 厂商资产登记

1. 用户选择本人有权使用的素材，并选择登记目标；页面显示供应商、具体渠道、账号／地区范围、适用模型、所需授权与外部处理限制。
2. M03 校验该渠道、模型和账户是否实际支持厂商登记；不支持或未开通时阻止提交并说明。
3. 用户确认材料来源及目标平台授权要求后，按素材类型进入登记。普通／虚拟素材仅在官方 API 和账号权益允许时由授权流程创建；真人素材必须由使用方发起官方邀请，由真人本人登录其供应商账号完成真人认证、授权和上传，再由使用方接收。平台只引导和同步状态，不代替真人同意或认证。
4. M05 建立登记申请并将厂商 Asset Group ID、Asset ID 或邀请／受理标识与源素材关联；状态进入处理中。用户可离开页面，之后查看同一登记状态。
5. 系统按官方支持的查询方式更新原始状态。只有 Asset 详情为 `Active`，且模型／渠道／项目／账户范围匹配、授权有效时，资产才能用于新任务；列表出现或 HTTP 请求成功不够。
6. 登记被拒、超时或状态未知时，展示可操作说明；只有厂商允许且原任务状态明确时才重试，未知状态先查原登记，避免重复创建。
7. 登记完成后，用户可在对应模型能力中选择该资产；切换渠道或账户时重新检查，不默认复用原 Asset ID。

### 7.3 失效、撤回与删除

1. 用户软删除或撤回素材／授权后，停止素材新展示、新引用和新任务使用；显示已有项目／课程／登记映射的影响摘要。
2. 已提交任务按 M04 固定输入快照继续核查，不因素材删除而伪造供应商任务失败；新提交须阻止。
3. 需要从厂商端删除时，M05 仅在该渠道有明确删除能力且用户授权后提交独立操作，并记录厂商确认或不支持状态。
4. 平台软删除与厂商端删除分别展示；一个成功不代表另一个完成。
5. 永久删除／匿名化遵循 M14 独立治理；必要的账务、任务和审计事实按保留规则处理，不经普通删除破坏。

### 7.4 作品或任务输出转为素材

- 用户可从已交付任务输出或本人作品主动“另存为素材／加入素材集”。
- 新素材保留来源任务／作品和对应许可；不复制公开分享权限、课程权或其他引用权限。
- 用户拒绝保存或删除派生素材，不改变源作品或历史任务事实。

## 9. 业务对象与状态

### 9.1 关键对象

| 对象 | 定义与重要属性语义 |
|---|---|
| 平台素材 | 媒介引用、所有者／提供者、来源、媒介类型、授权范围、状态、创建／更新时间、派生关系 |
| 平台素材授权 | 被允许的受众、动作、场景、地区／期限（如适用）、撤回／到期状态；权利声明不等于平台认证 |
| 素材集 | 用户或课程对素材的组织关系；删除素材集不删除成员素材 |
| 素材引用 | 项目、任务、课程、模板或作品与某素材版本／权限范围的关系 |
| 厂商登记申请 | 目标渠道、账户作用域、地区、精确模型能力、申请人、原素材、登记用途、外部受理标识和时间线 |
| 厂商资产组 | 厂商账号／项目中的分组标识、组类型、真人授权／期限摘要、成员资产数量及组级删除影响 |
| 厂商资产映射 | 厂商／渠道 Asset ID、Asset Group ID、账号／项目／区域、外部处理与可用状态、额度／期限摘要及最近核验时间 |
| 厂商临时预览地址 | 为查看详情临时产生的短期地址；不作为稳定 Asset ID 或长期平台素材地址 |
| 授权凭据引用 | 受限访问的声明／证明材料标识、范围、提交主体、状态；默认不在一般详情中展示原件 |
| 平台素材发布 | 平台素材可见范围、允许用途、授权版本、上下架时间和责任人；M06 的作品发布不归 M05 |
| 删除／撤回请求 | 用户／平台对平台素材或厂商映射提出的停止使用、软删除或外部撤回意图及执行结果 |

### 9.2 平台素材状态

| 状态 | 含义 | 对新引用／生成 |
|---|---|---|
| 上传中 | 平台尚未完成文件读取与基本检查 | 不可用 |
| 待补充声明 | 素材已接收，但用途或来源声明不足 | 不可进入受限用途 |
| 可用 | 平台素材可访问且其声明范围允许当前动作 | 仍需按 M03 能力和 M14 规则校验 |
| 受限 | 格式、授权、政策或其他条件限制部分用途 | 只可在详情列明的范围使用 |
| 失效 | 文件损坏、来源权限变化、授权撤回或其他原因导致当前不可用 | 阻止新引用／提交 |
| 软删除 | 用户已停止正常使用，可受控恢复 | 不可用于新任务 |
| 永久删除／匿名化处理中 | 已进入 M14 治理流程 | 按治理决定限制访问；不能由普通删除替代 |

### 9.3 厂商登记状态

| 状态 | 含义 | 新任务是否可引用 |
|---|---|---|
| 未登记 | 平台素材没有该目标范围的登记 | 仅当渠道允许普通素材输入时可用，不能按厂商资产引用 |
| 待确认条件 | 渠道、模型、账户、地区或授权资格尚未核实 | 否 |
| 已提交／Processing | 厂商已接受或正在预处理 | 否 |
| Active／可用 | 厂商资产详情确认已处理，且 M03 能力、授权和账号范围匹配 | 是，仅限匹配范围 |
| Failed／被拒 | 厂商明确预处理或授权失败，并可能附带错误码／原因 | 否；按原因允许修正后重新申请 |
| 未知／待核查 | 请求状态不明确、查询暂不可用或响应冲突 | 否；先查原申请 |
| 将到期／受限 | 资产临近到期、额度或权益受限 | 仅按厂商当前确认范围；可要求用户处理 |
| 已过期／失效 | 厂商确认不能再用或已超期 | 否 |
| 撤回中 | 已请求供应商撤销或停止使用 | 否 |
| 已撤回／外部已删除 | 厂商确认撤回／删除 | 否；保留历史登记事实 |
| 外部不支持删除 | 渠道没有可验证的删除操作，或厂商拒绝删除 | 不可继续新用；明确告知外部数据处理状态 |

厂商原始状态与平台映射状态并存。若渠道没有某状态查询能力，M05 显示“未核验／未知”，不得推断为可用或删除成功。

## 14. 分期与非目标

| 阶段 | 建议能力 | 状态 |
|---|---|---|
| 首发建议 | 私有图片／视频／音频上传和导入；目录／素材集／标签；预览、搜索、收藏、授权声明；平台精选素材；项目引用；素材可用性校验；必要且经验证的厂商资产登记及状态；软删除与引用影响提示 | 建议范围；厂商资产能力按账号开通结果条件性启用 |
