本文定义教学内容组织、课程访问资格、学习进度、课件与练习资源、案例和练习画布之间的业务关系。M10 的目标是帮助用户学会使用创作服务并回到创作，不默认建设完整教育平台、讲师交易市场或学习认证体系。

## 1. 模块目标

M10 为学员提供清晰、可持续访问的课程内容和练习路径；让受邀老师在运营授权范围内维护教学内容；让课程案例、素材、模板和生成练习分别遵守各自权限；在不把课程权误当作积分、作品授权或素材所有权的前提下，将学习转化为个人创作实践。

成功意味着：学员能辨认自己可访问的课程与课节、学习进度和练习入口；权限来源、范围和期限可解释；课程下架、授权撤回、视频失效或依赖模型不可用时，不丢失历史学习事实并给出后续选择；老师不能越权访问无关学员的私有项目、素材或作品。

## 2. 服务对象与主要任务

| 用户／角色 | 主要任务 | 权限边界 |
|---|---|---|
| 游客 | 浏览公开课程目录、介绍、目录和试看内容 | 仅访问明确公开内容；无私人学习进度和练习资产 |
| 学员／创作者 | 确认课程访问资格、学习课节、查看进度、保存课件、开始练习并返回个人画布 | 只访问本人有权课程和学习记录；课程权不自动包含积分、素材下载或作品公开权 |
| 受邀老师 | 维护被分配课程／课节、教学说明、练习任务与获授权案例 | 仅限被授予范围；不可自由入驻、独立定价、售课、查看无关学员私人资源或在系统内结算收入 |
| 课程运营 | 创建课程、组织分类与目录、配置访问范围、审核发布、下架或恢复课程 | 按岗位和对象授权；不得直接改写积分、订单、素材或作品事实 |
| 内容审核／安全岗位 | 处理课程内容、案例、举报或授权风险 | 按 M14 案件与最小必要原则访问；不拥有课程编辑事实 |
| 客服 | 协助处理无法解锁、视频／课件不可用和进度问题 | 可核查必要摘要并转交主责岗位；不直接伪造课程权益或学习完成状态 |

## 3. 范围与模块责任

### 3.1 M10 主责

- 课程、课程版本、分类、章节、课节、教学内容和发布／下架状态。
- 课程学习权益的授予、有效范围、暂停／撤销及访问判定；外部成交可作为受控授予依据，但不形成 M08 订单。
- 学员对课节的学习进度、最近学习位置和课程内反馈记录。
- 课程与案例作品、课件、练习素材、画布模板、练习任务的教学关系及所需授权引用。
- 面向学员和老师的课程页面，以及受控课程运营入口的业务规则。

### 3.2 M10 不负责

- M08 负责未来商品、平台订单、支付和退款事实。当前不提供线上售课、自动支付或产品内退款。
- M07 负责积分账户、报价、预占、实结和赠送积分账本。课程观看权不自动发积分；课程如附带积分，必须由明确授予依据交由 M07 单独入账。
- M01 负责项目、画布、工作流和模板实例化后的个人创作；M10 不重新设计画布，也不在课程系统中直接执行生成。
- M04 负责工具运行、生成任务和可靠交付；练习任务触发生成前仍需用户确认报价并遵守任务规则。
- M05 负责素材、平台素材及厂商资产；M10 只声明课程内可用范围，不重定义素材权属或厂商状态。
- M06 负责作品所有权、版本、分享及公开发布；课程案例只能引用明确获准展示的作品版本。
- M02 负责用户身份、角色授予及资源归属；M10 不直接创建老师管理员权限。
- M11 提供后台岗位入口；M12 提供通知与工单；M14 主责授权治理、审核政策、举报／申诉和隐私请求。

### 3.3 课程相关对象区别

| 对象 | 含义 | M10 处理规则 |
|---|---|---|
| 课程内容 | 课程介绍、章节、课节及教学文本／视频 | 由课程编辑权限维护，发布版本留有历史引用 |
| 课程权益 | 用户访问一门课程或指定范围内容的资格 | 明确授予主体、课程范围、来源、开始／结束时间和状态；不等于付款或积分到账 |
| 学习进度 | 用户已访问／完成的课节位置和最近学习位置 | 用户级记录，不作为考试成绩、证书或技能认证 |
| 课件下载权 | 对某份课件文件在约定范围内查看或下载的权限 | 与课程观看权分别定义；下载后无法保证收回用户本地副本 |
| 练习素材权 | 在明确课程／练习范围内使用指定素材的资格 | 由 M05/M14 的许可约束；不默认为商用或公开再分发 |
| 模板使用权 | 查看模板、复制为个人新草稿或按许可范围复用的能力 | 模板复制不复制模板所有权；实例化后由 M01 创建个人项目 |
| 案例作品引用 | 课程中展示经授权的作品版本 | 不开放源画布、未公开素材或作品原文件，除非另有明确授权 |
| 生成额度 | 用于练习工具／模型运行的积分或其他额度 | 由 M07 管理；课程权限不等于无限生成 |

## 7. 核心用户旅程

### 7.1 浏览、试看并获得课程权限

1. 游客或用户浏览公开课程目录和详情；详情明确哪些内容可试看、课程访问范围及配套权益。
2. 用户选择试看时，只能打开被标记为公开试看且当前可用的内容。
3. 完整课程权限来自免费公开规则、受邀授予或未来 M08 订单履约依据。当前如有外部线下成交／合作，运营按受控流程核对依据并授予课程权益，记录外部来源和操作人；不创建平台订单或支付记录。
4. 权益未生效时，页面提供状态和核查入口；不得仅凭“付款成功”截图自动宣称已解锁，也不得把 M08 支付成功当作 M10 已完成授予。

### 7.2 学习课节与记录进度

1. 学员打开有权限课程，M10 校验课程、课节、版本和当前授权状态。
2. 学员阅读图文或播放视频；系统展示最近学习位置和章节／课节完成状态。
3. 进度是学习导航与运营分析事实，不代表考试通过、掌握技能、完成全部课程或获得证书。
4. 学习过程中权限到期／撤销、课程下架或视频失效时，停止无权访问并保留历史进度；若存在申诉／客服处理，显示处理状态，不自行恢复权限。

### 7.3 从课程进入练习画布

1. 学员在课程课节中选择练习，查看练习目标、建议步骤、获授权模板／素材和依赖能力摘要。
2. M10 检查学员具备课程练习访问权；M05/M14 确认素材及授权；M01 确认模板可实例化并创建新的个人练习项目／画布。
3. 模板依赖模型已下架或不具备实际能力时，提供适用替代项或阻断原因，不把界面上的模型名称当作可用能力。
4. 用户在 M01 自行选择工具和模型，并在 M07 报价后确认生成费用；课程观看权不免除积分预占与可靠交付规则。
5. 生成结果由 M04 交付；用户如需沉淀作品，由 M06 显式保存。练习页不自动公开作业或案例。

### 7.4 老师编辑与运营发布

1. M02/M11 向受邀老师授予具体课程／内容范围的角色和期限。
2. 老师只能编辑被分配的课程、课节、教学说明、练习任务和已获授权案例引用；无权改课程价格、用户权益或其他模块源事实。
3. 内容修改形成待审核版本；在获授权课程运营／内容岗位通过后发布，未通过或待审版本不替换当前有效内容。
4. 课程更新、下架或恢复时，运营查看会受影响的已获权益、学习进度、模板、素材、案例及学习者告知；M10 记录内容版本和决策，M12 负责通知送达。

## 9. 状态、权益与业务规则

### 9.1 课程与内容状态

| 对象 | 状态 | 含义 |
|---|---|---|
| 课程 | 草稿、审核中、已发布、已隐藏／下架、已删除、治理限制中 | 只有已发布且可见范围允许时可进入目录；下架不自动抹除权益和学习记录 |
| 课程版本 | 编辑中、待审核、已发布、被替代 | 历史已发布版本保留可追溯引用；更新须明确适用范围 |
| 章节／课节 | 草稿、已发布、隐藏、内容不可用 | 课节状态受所属课程及自身发布状态共同限制 |
| 视频／课件资源 | 可访问、处理中、暂时故障、失效、授权受限 | 可见目录不保证媒体文件当前可播放／下载 |
| 练习定义／模板引用 | 可用、需替换依赖、不可用、授权撤回 | 由 M01/M03/M05/M14 的最新能力和授权事实共同约束 |

### 9.2 学习权益状态

| 状态 | 含义 | 访问结果 |
|---|---|---|
| 待生效 | 已有授予依据但开始时间未到或发放仍处理中 | 不开放受限课程；显示待生效原因 |
| 有效 | 用户当前可访问被授予范围 | 按课程／课节范围允许学习 |
| 已到期 | 授予期限结束 | 停止新的受限访问；保留进度和历史记录 |
| 已撤销 | 权益依据被纠正、退款规则执行或授权治理要求撤销 | 停止受限访问；显示可申诉／客服说明（如适用） |
| 暂停核查 | 权益有争议或治理限制待处理 | 按策略限制访问并提示处理状态，不伪装为永久撤销 |

### 9.3 学习进度状态

课节可区分未开始、进行中、用户标记完成；课程汇总展示学习比例或最近学习位置。视频播放进度只作为继续学习辅助信息，不能单凭播放时长宣称学习完成。是否允许用户手动标记完成为设计建议；无测验、批改或认证时不得出现“通过考试”“已掌握”或证书含义。

## 13. 风险、非目标与待确认事项

### 13.1 风险与控制

| 风险 | 影响 | 控制 |
|---|---|---|
| 将课程访问权当成所有配套权益 | 用户误以为可下载素材、复制模板或无限生成 | 课程详情、学习页和练习入口分项披露权益；M07/M05/M01 各自确认权限 |
| 人工发放权益伪装成平台销售 | 形成虚假订单／支付记录并混淆对账 | 标记外部凭据授予来源；不生成 M08 交易事实 |
| 课程更新破坏旧链接或学习进度 | 学员进度丢失、老师内容修改影响在学用户 | 课程版本化，记录课节历史引用，更新时提示影响 |
| 模板／厂商素材依赖失效 | 课程步骤无法复现或误导用户 | 展示当前能力状态，提供替代或阻断；不以宣传页能力代替实际核验 |
| 老师权限过宽 | 接触无关学员私有内容或运营敏感配置 | 按课程、内容对象、动作和期限授予；编辑与发布可分离 |
| 课程效果被宣传成生成保证 | 用户形成不现实预期或投诉 | 教学目标描述方法与操作，不承诺特定模型效果或成功率 |

### 13.2 少量待确认事项

以下事项不阻塞本轮草案，先按保守工作默认继续：

1. **课程是否进入首发对外体验。** 建议首发先不依赖课程；如内容已就绪，可作为少量免费／受邀课程试点。
2. **未来免费、单独购买、组合套餐或会员包含课程的商品形态。** 当前不启用线上售课和会员；如未来重新评估，建议逐商品列出课程范围与有效期，会员不默认解锁全部课程。
3. **课程访问资格的授予岗位与凭据标准。** 建议由 M11 授权课程运营处理，依据外部合同／成交凭据手工授予；不建立在线订单和复杂审批流。与积分手工入账凭据是否共用凭据规范需 M11 统一。
4. **既有学员遇课程下架时的访问处置。** 建议按下架原因、原授权承诺和治理决定分别处理；普通内容更新不自动收回既有权益，安全／权利问题可先限制并进入 M14 流程。
5. **进度的完成判定。** 建议首发仅记录最近位置及用户标记完成，不提供考试、认证或“掌握程度”结论。
6. **课件下载与缓存规则。** 建议首发默认不提供可下载的高风险原始素材；确需下载时逐项确认授权和范围，并提示本地副本不可保证回收。

上述建议不扩展已确认的经营模式，也不改变 M08 当前暂缓、老师受邀内容角色或 M07 积分主责。本轮只执行 P14；完成本文后停止，不自动执行 P15 或后续 Prompt。
