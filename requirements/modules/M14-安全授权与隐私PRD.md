## 1. 目标、范围与治理原则

M14 的目标是让用户与运营人员知道：素材／内容被用于什么目的、哪些权限已经明确、模型／供应商处理了什么、遇到拒绝或投诉如何处理、谁能访问敏感信息，以及普通删除与永久删除如何区分。治理决定必须可解释、可追踪、可申诉，并由受影响业务模块执行各自对象的限制或恢复。

治理原则：

1. **市场条件化。** 目标市场、用户所在地区、服务提供者角色、具体模型供应渠道不明时，法律义务和处理范围一律标注“上线前待核验”。中国大陆资料不作为全球结论。
2. **按对象与用途授权。** 用户上传不等于其有权使用；私人素材、厂商资产、作品发布、课程案例、模型输入和商业使用是不同用途，不互相推定。
3. **只收集必要信息。** 授权凭据、申诉附件、外部交易截图和安全案件采用最少字段、明确用途、限制访问和期限核查。
4. **源模块拥有业务状态。** M14 产生授权／安全／隐私治理决定；M02/M04/M05/M06/M10 等对象主责模块执行访问、任务、素材、作品／课程权益变化；M12 沟通，M11 承接后台待办。
5. **拒绝不等于授权或事实判断。** 供应商拒绝、审核拦截、举报和申诉分别是不同事实；不得单凭模型拒绝推断内容违法，也不得把通过审核当作权属证明。
6. **保护措施不用于规避。** 蒙版不得用于绕过真人判定、审核、身份验证、授权校验或供应商风控；拒绝后不得自动变换素材并反复试探审核边界。

## 3. 责任角色与治理权限

| 角色／岗位 | M14 相关职责 | 不得越权 |
|---|---|---|
| 普通用户／素材上传者 | 提供必要权利声明、选择允许用途、查看处理告知、申请本人数据权利、投诉或申诉 | 不能替第三方授予无权利的许可，也不能通过接受平台条款授权平台超出明确用途使用素材 |
| 内容／安全审核人员 | 依已发布规则检查公开作品、举报和高风险输入／输出，给出有依据的审核建议／决定 | 不得查看无关私有内容，不可只凭一次供应商拒绝判定违法，不披露内部阈值 |
| 隐私请求处理人员 | 身份核验、分对象查询／导出／更正／删除／限制处理请求，记录依据与决定 | 不得对账务／安全必要保留事实直接抹除；争议交由隐私负责人判断 |
| 授权治理负责人 | 维护政策版本、投诉处理规则、升级／申诉范围和模块影响指引 | 不得替业务模块写入余额、任务状态或作品发布事实 |
| 业务事实主责模块 | 接收 M14 决定并执行对象访问、暂停、撤回、下架、恢复／删除等处理 | 不得忽略治理决定或自行扩大对其他业务对象的处罚范围 |
| 客服（M12） | 接收用户表述、传递安全化进度、补充用户材料和申诉请求 | 不能自行判断侵权、合规、授权真伪或永久删除已完成 |

## 4. 授权与告知矩阵

授权不是一个全局勾选项。每次使用前，产品应能显示或核查权利主体、来源、用途、受众、渠道／地区、有效期和撤回状态中适用的字段；用户陈述不代表平台已鉴定其真实性。

| 对象／数据 | 用户动作前需告知／确认的事项 | 使用范围与主责 | 撤回／失效影响 |
|---|---|---|---|
| 用户自有图片／视频／音频／文本素材 | 文件归属、使用目的；素材是否会发送给具体模型／供应商；发送哪些参考内容；供应商保留／删除能力如未核实须明确提示 | M05 管素材与授权摘要；M04 管实际任务输入和供应商传递事实；M14 定义授权要求 | 停止新的引用／提交；已运行任务按 M04 核查；历史任务、作品和必要审计按保留规则评估 |
| 第三方素材／肖像／声音 | 上传者声明权利基础及允许范围，特别区分创作生成、私人使用、商业使用、公开发布、课程展示和分享 | M05 管素材记录，M14 管授权／风险策略；供应商可另有资格或资产要求 | 停止新的使用／传播；既有公开作品、课程引用和供应商资产逐项评估，不承诺仅撤回一项就自动回收所有外部副本 |
| 未成年人相关素材 | 首发真人素材不处理未成年人；素材疑似涉及未成年人时提供停止使用／删除或转治理的入口；是否允许任何未成年人账户待市场评审 | 当前用户已明确禁止未成年人真人素材处理；账号年龄政策另待确认 | 阻止新任务／公开；必要时进入 M14 核查；不要求用户通过蒙版规避限制 |
| 模型／供应商输入 | 具体能力／渠道使用到的提示词、参考媒体、厂商资产 ID 和任务信息；已知地区／保留／训练政策；未知项必须标为未知 | M03 管渠道与官方协议能力；M04 管实际提交；M05 管厂商资产；M14 提供告知原则 | 供应商政策变化时重新评估新提交；运行任务按 M04 状态处理；不得承诺上游已删除除非取得可核实结果 |
| 厂商登记资产 | 登记对象、提交供应商、授权凭据用途、厂商资产状态含义、有效范围／期限（若供应商提供） | M05 主责外部资产映射及状态；M03 提供能力约束 | 失效／授权撤回后阻止新引用；供应商侧删除或撤回能力取决于实际 API／条款，不能冒称平台可控 |
| 公开作品／案例 | 用户逐项选择媒体、作者信息、说明、提示词／参数摘要、参考素材来源和公开受众；说明 AI 标识与授权处理 | M06 主责作品分享／发布记录；M10 主责课程引用范围；M14 主责安全与治理决定 | 撤下平台页面／引用；外部已下载／缓存内容无法由平台保证回收 |
| 课程内容／课件／练习模板 | 老师／运营须有课程范围内使用权；学员观看权、下载权、素材使用权、模板复制权和公开作业权分开告知 | M10 主责课程权益／内容关系；M05/M01/M06 分别主责素材／模板／作品 | 停止新增访问或引用，按已有学员权益和治理决定处理；保留历史学习／授权事实 |
| 财务／身份／授权凭据 | 收集目的、后台可查看岗位、遮挡无关字段建议、关联业务对象和保留期限（未知时待确认） | M11 主责受限外部凭据操作记录；M07 主责积分账本；M02/M14 管身份／隐私范围 | 按隐私请求及必要记录规则限制、脱敏或处理，不将凭据用于无关分析 |
| 客服／安全案件附件 | 谁可查看、附件用途、内部备注与用户可见回复的区别、如何补充／撤回 | M12 管工单和受众；M14 管案件访问规则 | 工单关闭不等于附件自动删除；按 M14 案件保留／隐私处理规则执行 |

### 4.1 上传前、提交前与发布前告知

- **素材上传前：** 告知支持的素材类型、默认私有、平台处理目的、是否进入厂商资产登记及需由用户另行发起的操作；不能暗示上传即取得授权。
- **生成提交前：** 在用户确认报价与提交前，明确选中的提示词／素材／资产将发送至实际供应渠道；尽可能标明渠道主体、地区和其可核验的数据处理说明。若关键留存／训练／跨境信息未确认，应提示未知并按风险级别限制使用，而非用“安全”空泛承诺覆盖。
- **公开／分享前：** 对每个披露字段展示受众；分享私有作品不自动分享源项目、供应商凭证、完整执行日志、他人作品或未选素材。
- **厂商登记前：** 告知目标厂商／渠道、需提交的文件／权利凭据、登记目的、资产状态含义及外部处理不确定性；由 M05 实际核对资格和状态。
- **课程引用前：** 区分观看案例、下载课件、复制模板、素材练习和公开作业授权；课程权益不能扩张为原素材／作品权利。

本节严格执行用户已明确约束与 GLB-016、GLB-041：

## 6. 内容安全审核、拒绝与申诉

### 6.1 审核对象与决策来源

节点或工作流中的“确认后继续”、候选采用、导演设置确认和预算确认属于创作流程门禁，不属于本节的内容安全审核。创作确认通过不能推导为素材已授权、内容安全通过、允许公开或隐私处理完成；M14 的治理决定也不能自动替代用户对候选版本和执行范围的创作确认。

| 对象／事件 | 谁提供事实 | M14 的职责 | 用户可见边界 |
|---|---|---|---|
| 输入素材授权声明 | 用户提交、M05 记录 | 定义风险策略与所需核查；争议时冻结新使用并建立案件 | 展示要求补充的授权／来源信息，不将声明等同于认证 |
| 供应商拒绝生成 | M04 记录供应商原状态／安全化错误 | 评估需否限制平台侧用途、建立规则或申诉；不替供应商改原状态 | 告知请求未能继续及可行合规替代；不提供绕过过滤的提示词／素材修改方法 |
| 平台内容审核 | 获授权内容审核岗位 | 定义规则版本、决定状态、理由类别和可申诉范围 | 给出安全化主要原因和后续动作；不泄露内部检测参数、他人举报人信息 |
| 用户举报／版权或肖像投诉 | 举报人提交关联 URL／作品／权利主张和必要材料 | 受理、补充证据、临时风险措施评估、决定或转交专业治理 | 举报成立与否待核，不因单次举报自动认定侵权；必要限制需说明范围和复核方式 |
| 课程／素材／案例授权撤回 | 权利人、用户、供应商或业务模块的可核查通知 | 验证来源与适用范围，决定需要暂停、下架或继续使用的事项 | 说明对已发布作品、学员、既有项目／任务的分别影响 |
| 隐私／安全请求 | 用户本人或其授权代表 | 完成身份核验、范围识别与跨模块决定／协调 | 告知已完成、部分完成、需要补充、限制或拒绝的范围与原因 |

### 6.2 内容安全处理状态

| 状态 | 含义 | 用户可见行为 |
|---|---|---|
| 待检查 | 已提交内容／发布申请待适用规则检查 | 内容尚未获准公开／执行时说明等待状态 |
| 允许继续 | 当前规则和能力检查未阻断所申请用途 | 仅表示该流程阶段可继续，不是权属认证或未来结果保证 |
| 需补充信息 | 权利、用途、资产状态或身份范围不足以做决定 | 说明需要的材料类别与提交入口；不要求无关敏感信息 |
| 供应商拒绝 | 实际渠道拒绝处理请求 | 显示安全化错误摘要；任务／积分按 M04/M07 状态处理 |
| 临时限制中 | 风险核查、举报或授权争议期间暂时限制指定内容／用途 | 说明限制范围、时间／复核状态和申诉入口；不扩大到无关资源 |
| 已限制／已下架 | M14 或授权岗位已决定的治理措施 | 展示安全化决定摘要、受影响对象和申诉方式 |
| 申诉中 | 用户对拒绝、限制或下架提出复核 | 原决定按其风险级别维持或采取暂时措施，展示复核进度 |
| 已恢复／已撤销决定 | 复核后调整原决定 | 对应业务模块恢复允许范围；保留决定版本与影响记录 |
| 已结案 | 决定与告知已完成；相关模块完成执行或说明无法执行部分 | 用户可查看结案范围；重新发现新证据时可提交新申诉／工单 |

供应商拒绝、平台审核拒绝和权利投诉分别记录。客服不能把“供应商拒绝”改成“平台违规”，也不能把一次审核通过当成永久许可。

### 6.3 投诉与申诉流程

1. 用户选择要投诉／申诉的生成任务、素材、作品、公开页面、课程引用或账号决定；提交简短理由和必要证据。
2. 系统生成独立案件编号，并给出受理状态、当前限制范围和用户可以采取的安全行动。
3. M14 确认案件类型、处理权限、所需材料和受影响业务对象，按敏感级别分配审核／隐私岗位。
4. 若需临时隐藏、暂停新生成或限制资源，说明理由类型、所限对象和重新评估条件；临时措施不预设最终违规结论。
5. 复核人员查看原始输入、源模块状态、所适用规则／供应商能力版本和用户补充材料；原处理人是否回避复核由风险政策另定，建议高风险案件采用独立复核。
6. 决定通过、部分通过、维持、撤回或需要外部处理；记录原因摘要、决定人、规则版本、受影响对象和申诉路径。
7. M02/M04/M05/M06/M10 等事实主责模块执行其业务对象的限制／恢复；M12 向用户告知可披露结果；M11 跟踪待办；M13 仅统计去标识化类别与处理状态。

时限、证据标准、重复／恶意举报处理和法律正式通知渠道依目标市场及运营安排待确认，不在本稿虚构法定或平台 SLA。

## 7. 个人信息权利与隐私请求

### 7.1 用户请求类别

| 请求类别 | 产品处理路径 | 事实主责模块／限制 |
|---|---|---|
| 查阅／复制／导出 | 用户提交请求并完成适当身份核验；展示可提供的本人个人信息类别和导出范围 | M02 账户档案；各模块提供本人项目、素材、任务、作品、积分、课程、工单等可导出数据；M14 协调范围 |
| 更正／补充 | 指明错误字段或对象，确认归属后向对应主责模块提交 | M02 改身份资料；M03/M05/M06/M07/M10 等只改自己拥有的业务事实，不改历史账本／审计原记录 |
| 删除／注销 | 进入独立隐私请求流程，先识别账户数据、内容对象、厂商资产映射、任务／作品和必须保留事实 | M02/M14 协调；各模块分别处理；平台不得承诺同步删除供应商侧数据，除非有可核查删除结果 |
| 限制／撤回特定处理 | 说明撤回的素材、授权用途或可选处理，按请求范围停止未来使用 | M05 停止新引用；M04 核查在途任务；M06/M10 更新分享／案例；已完成任务和账本历史不静默改写 |
| 解释处理规则 | 展示适用于该用户的服务说明、处理目的、被访问对象和可用权利入口 | M14 提供规则解释；涉及供应商条款时只展示已核实信息 |
| 个人信息投诉／安全事件 | 建立受限案件、评估是否需要限制访问、通知或调查 | M14 主责判断与协调；系统通知由 M12 发送 |

### 7.2 隐私请求状态

| 状态 | 含义 |
|---|---|
| 已收到 | 请求有编号，但尚未确认身份／范围 |
| 身份或范围核验中 | 需核验申请人权限或识别跨模块对象 |
| 等待用户补充 | 缺少必要信息；说明仅要求完成处理必需的材料 |
| 处理中 | 各事实主责模块正在查询、导出、限制或评估删除影响 |
| 部分完成 | 可处理部分已完成，其余部分受保留规则、外部依赖或技术限制，逐项说明 |
| 已完成 | 确认各适用模块已返回执行结果；注明供应商外部状态是否可验证 |
| 部分拒绝／无法处理 | 对具体范围说明原因类别、依据评审状态和可用申诉渠道，不用笼统“系统不支持”结束 |
| 申诉／复核中 | 对范围、决定或执行结果提出复核，原请求历史保留 |
| 已结案 | 用户已获安全化结果；新事项可再次提交 |

不在文档中承诺法规未核验的固定处理时限。涉及儿童信息、敏感个人信息、身份／生物识别、跨境传输或第三方凭据时，必须进入对应限制与法务／隐私评审。

## 8. 数据访问、保留、删除与跨境待核验

### 8.1 普通软删除与永久删除／匿名化

| 数据／业务对象 | 普通软删除／撤下的产品效果 | 永久删除／匿名化及历史影响 |
|---|---|---|
| 用户自有素材（M05） | 停止正常展示、搜索、新引用和新生成；允许按权限恢复 | 由 M14 与 M05 核实授权、法定／合同保留及厂商映射；外部供应商删除能力单独核查 |
| 厂商资产映射（M05） | 停止该渠道新使用并记录登记／撤回／失效原因 | 不等于删除供应商资产；仅在供应商提供可核查能力时显示外部删除／撤回状态 |
| 任务输入、运行与交付（M04） | 按各对象策略停止展示／新操作；运行事实和扣费／交付追溯不被普通删除破坏 | 账户隐私请求时评估是否限制处理、去标识化或保留必要事实；M04/M07/M14 协同 |
| 作品／公开发布（M06） | 作品软删除停止列表、搜索、新分享／引用；发布撤下停止平台公开访问但不等于删除私人作品 | 永久删除／匿名化由 M14 流程协调；外部已下载／缓存副本不保证回收 |
| 课程学习与权益（M10） | 按课程／权益状态停止新访问，保留按适用规则需要的学习／权益处理记录 | 课程、学习记录和账户请求分开评估，不因删除课程内容伪造权益未曾存在 |
| 积分账本／交易凭据（M07/M11；未来 M08） | 不提供普通删除积分历史或外部凭据的操作；限制普通展示并最小化访问 | 依法／契约需保留与隐私权利冲突的具体依据由法务核验；不通过软删除破坏账务追溯 |
| 工单／投诉／审计（M11/M12/M14） | 从普通搜索／队列隐藏已结案或软删除对象，仍可受控核查 | 依安全、争议、法规必要性和最小化评估期限；不得无目的永久保存原始附件 |

普通软删除由对象主责模块实现；永久删除／匿名化不是普通“删除”按钮，而是 M14 统筹评估、逐模块执行并记录结果／例外的治理流程。具体保留期限目前全部待确认。

### 8.2 供应商传输与跨境信息

- 在每一模型／供应渠道上线前，由 M03/M04 记录可核验的服务主体、数据地区、输入类型、使用目的、保留／删除说明、训练使用说明（如公开／合同可确认）、错误日志范围和外部资产条款。
- “官方 SDK”或“官方协议”只说明调用协议来源，不自动证明数据不留存、不训练、不跨境或满足任何隐私要求。
- 对用户选择供应渠道前，产品应按可核验信息提供告知；未知信息显式标记，不能用泛化承诺代替供应商条款核验。
- 数据跨境、委托处理、共同处理、供应商再委托、用户请求的上游删除和监管／备案要求均列为市场与渠道上线前待核验项；本 PRD 不做技术或法律结论。

### 8.3 平台员工访问限制

| 数据类别 | 默认访问 | 扩大访问条件 |
|---|---|---|
| 普通账户与课程状态 | 客服／课程运营只看业务处理必要摘要 | 具体用户工单或受限岗位理由 |
| 私有项目、素材、作品原件 | 默认所有后台岗位不可浏览 | 明确客服／安全案件、用户授权或治理要求；申请范围、访问人和时间留痕 |
| 外部付款／退款凭据 | 限授权财务岗位查看 | 与具体 M11 外部入账／扣回操作关联；其他岗位只看存在性与脱敏摘要 |
| 供应商密钥、访问令牌 | 限供应商运营执行安全轮换，不向一般岗位显示明文 | 界面不得回显或写入工单／通知；仅保留掩码标识和操作事实 |
| 原始供应商错误／安全阈值 | 限供应商／安全运营必要范围 | 用户只收到安全化原因摘要；内部调查需有明确工单／案件 |
| 举报人身份与举报证据 | 限 M14 案件岗位 | 需处理举报、申诉或依法定程序请求；通知内容不得泄露身份 |

所有后台敏感访问须有业务理由和最小范围；对访问／导出／下载的留痕由 M11/M14 按岗位权限展示。系统管理员不因角色名获得默认全量数据可见性。

## 10. 风险处置、通知与错误修复

- **举报不等于定案：** 接收举报后可按风险采取限定对象、限定受众和可复核的临时措施；调查结束前避免对用户作确定性侵权／违规断言。
- **供应商拒绝生成：** M04 记录实际拒绝状态；用户收到安全化提示与可申诉／合规替代入口；M07 按用户已确认规则处理预占。客服不承诺任务失败已成立，直到 M04 核查完成。
- **误限制／误拒绝：** 复核通过时，M14 记录撤销／调整决定，M04/M05/M06/M10 恢复适用访问或使用；若造成费用／权益问题，由 M07/M08/M10 各自主责判断补救，M12 通知用户。
- **高风险紧急措施：** 可由已授权岗位临时限制明确对象以降低持续影响；须记录理由、范围、操作者、开始时间、复核责任人／条件和用户申诉入口。紧急限制不自动扩展为账户永久封禁。
- **记录错误：** 授权状态、审核结论或隐私请求的误记使用追加纠正／新决定，保留历史版本与原因；不得抹去原投诉或审计事实。
- **通知：** M12 仅在源模块确认决定／变化后发送；消息失败不改变处置事实。标题和正文不能泄露举报人、敏感附件、审核阈值或账户安全细节。

## 14. 上线前待核验事项与非目标

以下事项是上线门槛或待决策项，不阻止本 PRD 草案完成，但未解决前对应高风险能力不能被描述为已合规：

1. **目标市场与经营主体：** 首发用户／运营地点、经营实体、服务语言、应用分发／网站形态、公众可访问范围及 Cruio 在不同地区的服务角色。
