## 2. 模块目标

### 2.1 服务对象

- 普通创作者：从空画布、素材、作品或模板开始完成图片／视频创作。
- 学员：从有权限的课程练习模板进入自己的项目。
- 受邀老师：维护被分配课程的模板、案例和练习入口，不访问学员无关私有项目。
- 运营人员：发布平台创作工具和模板，核查用户可见的创作上下文，但不改写任务、积分或素材事实。

### 2.2 要解决的用户任务

1. 创建、打开、归档、恢复和复制项目。
2. 在可恢复画布中组织文本、剧本、角色、场景、道具、镜头、分镜、素材、工具、模型操作、任务投影和结果。
3. 从素材库、作品或课程引入获授权内容，并看见缺失、失效或无权限状态。
4. 选择当前实际可用的模型能力和参数，理解预计积分并明确确认报价。
5. 提交生成后离开页面，稍后仍能看到由 M04 提供的真实任务状态和结果。
6. 从多个结果中选择继续创作或保存作品，不把任意任务输出自动当作作品。
7. 在误操作、刷新、断线或多标签页编辑后尽可能恢复，且不制造重复任务或重复扣分。

### 2.3 成功定义

- 用户可在不理解供应商和后台实现的前提下走通“创作上下文—报价确认—任务投影—可靠交付—继续创作／保存作品”。
- 项目、画布和工作流定义可以恢复；页面关闭不影响已提交生成任务。
- 画布不越权拥有模型、素材、任务、积分、作品、课程或治理事实。
- 候选应用的成熟体验可被保留，但短剧专用流程、单机假设和内置经营逻辑不会强加给本产品。

### 3.4 复用结论与缺口

1. Toonflow 固定提交已被用户确认为首发应用级基线；保留其创作内核，但其单机／默认管理员假设、用户自配模型和原任务／积分语义不能直接成为 Cruio 业务规则。
2. 自由画布应作为通用入口；剧本、剧集、场次、镜头和分镜作为可选专业模式，除非后续用户定位明确要求强制短剧流程。
3. Open Canvas、火宝短剧和 React Flow 调研结论仅保留为历史对照，不再并行投入首发验证。
4. 首发沿用 Vue 3、Vite、Vue Flow、TypeScript、Bun、Express 和现有 workspace；不进行 Vue→React、Next.js 或 Python 主后端重写。
5. Python 仅在未来出现明确媒体处理、超分、批处理或模型执行需求时作为独立 Worker 评估。
6. 复用完成仍须通过同一组端到端场景验证；MIT 和代码可运行不等于多用户 SaaS、任务恢复、积分一致性或生产容量已经满足。

## 4. 范围与边界

### 4.1 本模块负责

- 项目创建、命名、列表、打开、归档、恢复、复制和软删除。
- 画布文档、视口、节点、连接、分组和工作流定义／版本。
- 文本与专业创作内容节点，包括故事、剧本、角色、场景、道具、镜头和分镜；专业层级按模式启用。
- 创作工具定义、版本、发布状态、工具库和工具节点。
- 素材、作品、模板、课程内容进入画布的引用入口和可见状态。
- 模型能力／参数的呈现、输入组织、报价确认入口和生成请求发起。
- M04 任务状态、执行日志摘要和交付结果在画布中的投影。
- 结果选择、继续创作、发送到素材／作品的入口。
- 单人编辑下的撤销重做、自动保存、恢复和多标签页冲突反馈。
- 首发图片手动遮挡、模糊、指定区域编辑和经授权局部重绘入口。

### 4.2 本模块不负责

- 不维护账户、角色或资源归属事实（M02）。
- 不决定真实可用模型、渠道和参数能力（M03）。
- 不执行、取消、重试或裁定生成任务状态（M04）。
- 不上传后成为素材主记录，也不登记厂商资产（M05）。
- 不把结果自动保存或公开为作品（M06）。
- 不计算余额、建立预占、实结或扣回积分（M07）。
- 不管理课程权益或学习进度（M10）。
- 不改变审核、授权或永久删除决定（M14）。

### 4.3 首发深度

首发覆盖单人项目与画布、基础工作流、平台发布的封装 Prompt 工具、素材／作品／课程模板入口、实际可用模型与参数展示、报价确认、任务投影、结果回填、图片手动区域编辑、自动保存与恢复。实时多人协作、复杂子流程、高级白板、第三方工具市场、完整剪辑、超分、视频／音频隐私处理暂不进入首发。

### 4.4 三类建设边界对照

| 类别 | 保留现成体验 | 定制体验 | 外接经营／事实模块 |
|---|---|---|---|
| 项目 | 列表、卡片、打开与最近使用 | 归档、复制、软删除、恢复、权限反馈 | M02 归属；M14 删除治理 |
| 画布 | 拖拽、缩放、连线、选择、分组、快捷操作 | 本产品节点语义、兼容校验、模式切换、冲突处理 | M02 权限；M13 只读汇总 |
| 素材 | 拖入、预览、节点引用 | 缺失／失效／无权限反馈和替换 | M05 素材与厂商资产；M14 授权 |
| 模型 | 参数面板和生成操作布局 | 由能力快照动态呈现、报价变化提示 | M03 能力；M07 报价与预占 |
| 任务 | 占位卡、进度和错误展示 | 跨会话恢复、未知状态、重复提交保护 | M04 任务；M12 通知 |
| 结果 | 预览、选择、连接下游 | 多结果选择、来源追溯、继续创作 | M04 交付；M05/M06 保存去向 |
| 工具／模板 | 工具库、拖入画布、实例化 | 版本、适用范围、缺失依赖提示 | M10 课程权；M11 发布入口；M14 安全 |

## 6. 信息架构与页面

### 6.1 项目列表

核心信息：项目名、封面／摘要、最近编辑时间、创作模式、保存状态、运行中任务提示、归档／软删除状态。核心操作：新建、打开、重命名、复制、归档、恢复和删除。空态应提供“空画布开始”和有权限模板入口；加载失败时保留重试和联系客服入口。

### 6.2 新建项目入口

入口包括空画布、平台模板、课程练习模板、从本人作品继续创作和复制本人项目。创建前说明将复制哪些结构和内容；缺失素材、无权限引用或已下线工具必须在进入画布前后明确列出，不以静默删除代替。

### 6.3 画布工作区

项目详情提供独立的项目画布入口。项目画布保存项目自身的创作布局和上下文，可引用工作流版本；工作流库提供独立入口，用于创建、打开和编辑用户拥有的工作流图。项目可以引用本人多个工作流，同一工作流版本也可以被多个项目引用。项目内显示的“已引入工作流”是引用，不表示该项目拥有工作流定义。

- 顶部：项目身份、保存／冲突状态、撤销重做、运行摘要和退出入口。
- 左侧资源区：创作内容、素材、工具、模板和可用节点入口；具体菜单可随复用候选调整。
- 中央画布：节点、连接、分组、视口、框选、复制和删除展示项。
- 右侧属性区：选中节点的输入、参数、引用、能力限制、预计积分和错误。
- 任务／日志区：M04 的任务状态投影和面向用户的执行摘要。
- 结果区：候选结果、选中结果、继续创作、保存为素材或作品的入口。

### 6.4 关键状态反馈

| 状态 | 用户反馈 |
|---|---|
| 自动保存中／已保存 | 显示最近确认保存时间，不用永久旋转图标代替结论 |
| 保存失败 | 保留本地编辑上下文，提示重试／导出恢复入口；不得显示“已保存” |
| 多标签冲突 | 说明哪个版本较新，允许刷新到最新、另存副本或放弃当前未保存改动 |
| 素材失效／无权限 | 保留节点位置和引用摘要，阻止新生成，提供替换或返回来源入口 |
| 报价失效 | 阻止提交，刷新报价并要求再次确认 |
| 任务未知 | 显示“核查中”，不显示成功／失败，不建议自动重复提交 |
| 可靠交付失败 | 保留任务和故障关联；积分由 M07 按全局规则释放 |
| 项目已归档 | 只读或受控恢复；运行中任务仍按 M04 状态展示 |

### 6.5 工作流复用与版本升级

1. 工作流库是与项目列表并列的入口；工作流归属于创建用户，并可在没有项目的情况下创建和编辑。
2. 用户可在多个本人项目中引入同一个有权访问的工作流。每个项目的引用固定引入时的版本；源定义的后续编辑形成新版本。
3. 项目详情显示已引入版本与源最新版本。用户可主动将单个项目引用升级到源最新版本；其他项目的引用不受影响。
4. 项目画布保存项目自己的节点和连接；工作流图保存工作流定义。二者各自恢复和校验权限。
5. 项目归档或删除不自动删除独立工作流；项目引用失效时保留可解释的来源与版本信息，具体删除保留规则由 M14 治理。
6. 用户可将已引入的工作流作为引用节点放入项目画布，节点显示项目固定版本并可跳转源定义。移除画布节点只改变项目布局，不解除项目引用，也不删除源工作流；服务端拒绝未引入或无权访问的工作流引用。

## 7. 关键用户流程

### 7.1 从空画布开始

1. 用户创建项目并获得个人归属。
2. 系统建立空画布并显示可用内容／工具节点。
3. 用户添加文本、素材或工具并连接。
4. 自动保存画布结构；尚未确认生成前不产生任务或积分预占。

### 7.2 从素材库加入参考图

1. 用户打开 M05 素材选择入口。
2. 只显示其有权使用且当前可引用的素材。
3. 用户选择后，M01 创建素材引用节点而非复制素材主记录。
4. 素材失效时保留引用和原因，阻止依赖它的新生成并允许替换。

### 7.3 从作品继续创作

1. 用户从 M06 选择本人作品或允许再创作的作品。
2. 系统根据授权创建新项目或结果引用节点。
3. 公开可见不自动带来原提示词、素材或完整画布复制权。
4. 新项目归属当前创建者，并保留来源关系。

### 7.4 从课程打开练习模板

1. M10 确认课程和模板使用权。
2. M01 实例化新项目；学员拥有新项目，老师不因此获得访问权。
3. 缺失素材、失效工具或无生成额度分别提示，不把课程权等同于生成权。
4. 课程权益后续撤回不自动删除学员已经合法创建的私有项目。

### 7.5 报价确认与生成

1. 用户选择实际可用模型／参数，M01 组织生成请求。
2. M03、M05、M14 分别返回能力、资产和授权校验；M07 返回报价。
3. 用户确认报价；任一影响价格的输入变化均使旧确认失效。
4. M07 预占成功后，M04 建立任务；M01 只显示任务投影。
5. 可靠交付后结果回填；M07 实结。失败释放预占；未知保持预占并人工核查。

### 7.6 多结果选择和继续生成

1. M04 返回一个或多个可靠交付结果。
2. M01 明确显示全部可用结果和当前选择，不因选择一个而删除其他结果。
3. 用户可将选中结果连接到下游节点、保存为素材或保存为作品。
4. 再次生成是新的明确请求、报价、预占和任务；不得复用旧扣费事实。

### 7.7 离开页面与恢复

1. 用户提交后可关闭页面或切换项目。
2. M04 继续跟踪任务；M01 的画布占位不承担执行。
3. 重新打开时先恢复画布，再取得 M04 最新状态与可访问结果。
4. 旧缓存状态不得覆盖较新的任务事实。

### 7.8 误删卡片

1. 删除普通未运行节点可通过撤销恢复。
2. 删除任务卡只移除画布展示，不取消 M04 任务、不释放积分。
3. 若用户确实要取消，必须发起独立取消请求并等待 M04 明确结果。

### 7.9 多标签页修改

1. 每个标签页显示自己基于的画布版本和保存状态。
2. 检测到较新版本时停止静默覆盖。
3. 用户选择加载最新、另存副本或放弃当前变更。
4. 已提交任务与历史工作流版本不因冲突解决被改写。

## 9. 业务对象与状态

### 9.1 主责对象

| 对象 | 业务语义 | 重要状态 |
|---|---|---|
| 项目 | 用户组织持续创作活动的容器 | 草稿、活跃、归档、软删除 |
| 画布文档 | 当前可编辑和恢复的空间布局与创作上下文 | 未保存、保存中、已保存、保存失败、冲突 |
| 工作流定义 | 节点、连接、输入输出和执行顺序 | 草稿、有效、失效引用 |
| 工作流版本 | 某次运行引用的不可静默改写快照 | 已形成、被运行引用 |
| 项目工作流引用 | 项目与有权访问的工作流版本的关联 | 有效、来源失效、无权限 |
| 节点 | 画布中的内容、引用、工具、任务投影或结果单元 | 正常、缺失依赖、无权限、失效、软删除 |
| 连接 | 节点间允许的内容传递或执行依赖 | 有效、不兼容、断开 |
| 工具定义／版本 | 平台封装的创作任务及某时点规则 | 草稿、已发布、已下线 |
| 模板 | 可被授权实例化的项目／工作流结构 | 草稿、已发布、已下线、依赖缺失 |

### 9.2 非主责投影

| 投影 | 源模块 | M01 允许做什么 | M01 不得做什么 |
|---|---|---|---|
| 素材状态 | M05 | 显示、引用、替换 | 改素材主记录或厂商资产状态 |
| 模型能力 | M03 | 展示可用选择和参数 | 自行宣称模型可用 |
| 任务与日志 | M04 | 显示、发起取消／重试申请 | 直接改成功、失败、未知状态 |
| 积分报价／预占／结算 | M07 | 展示并承接确认 | 改余额或自行扣分 |
| 作品 | M06 | 发起保存／继续创作 | 自动创建公开作品 |
| 课程权益 | M10 | 提供练习入口 | 授予课程或生成额度 |
| 治理决定 | M14 | 执行阻止、隐藏或提示 | 绕过审核或授权决定 |

项目归档、软删除和画布节点移除都不等于任务取消。工作流版本一旦被运行引用，后续编辑形成新版本语义，不改写历史运行。

## 14. 分期与非目标

### 14.1 分期

| 阶段 | 功能深度 |
|---|---|
| 首发 | 单人项目和画布；空画布；基础内容／素材／工具／任务／结果节点；平台封装 Prompt 工具；模型参数和报价确认；自动保存、恢复、撤销重做、多标签冲突；任务回填；结果继续创作；图片手动区域编辑 |
| 下一阶段 | 剧本／角色／场景／道具／镜头／分镜专业模式；课程模板；更完整模板运营、多结果历史和项目恢复体验 |
| 后续 | 经验证的团队协作、复杂子流程、高级白板、第三方工具生态、超分、完整剪辑及其他隐私编辑能力 |

### 14.2 明确非目标

- 首发不再并行验证 Open Canvas、React Flow 自研、Next.js／React 重写或 Python 主后端路线。
- 不因应用候选存在而删除 M02～M07、M10～M14 的业务主责。
- 不提供实时多人协作、无限节点规模承诺或第三方任意代码节点。
- 不提供完整非线性剪辑器、超分或视频／音频隐私处理。
- 不处理未成年人真人素材、人脸识别、身份比对或活体认证。
- 不以蒙版绕过真人判定、内容审核、授权校验或供应商风控。
- 不在本模块设计积分账本、厂商资产登记、订单支付或平台退款。

- 首发以个人创作者和单人编辑为主。

- 首发只开放少量已核验模型和平台发布工具。
- 私有作品与可控分享优先，公开案例不作为首发主链前置。
