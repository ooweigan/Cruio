# Upstream provenance

Cruio V1 uses code from the Toonflow application as an application-level baseline.

- Repository: <https://github.com/HBAI-Ltd/Toonflow-app>
- Upstream branch at evaluation time: `master`
- Fixed commit: `d86cce6b689916ab73f75bc4c1f42a2a7424516c`
- License: MIT; the original copyright and license text is retained in `LICENSE`.
- Imported stack: Vue 3, Vite, Vue Flow, TypeScript, Bun, Express, and the upstream workspace layout.

Cruio does not claim rights to the Toonflow name or logo. Upstream promotional images,
QR codes, sponsor graphics, screenshots, sample media, and logo binaries were not imported.
The Cruio SVG mark in `packages/assets/logo.svg` is a new project asset.

The Electron workspace remains only as upstream reference code. It is not part of the
Cruio V1 Web build or documented startup path.
