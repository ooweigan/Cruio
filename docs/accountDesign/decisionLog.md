# Cruio 账户设计决策与待确认清单

更新日期：2026-11-03。用途是明确设计依据和需要决定的选项，避免把视觉稿中的示意内容误当已批准功能。第一版范围以 `accountPlan.md` 开头的定稿为准。

## 实施阶段更新

用户已授权智能体分别开发并由独立智能体验收，且明确选择“没有已有账号服务，采用最小独立账号服务”。A01/A02 已收敛为账号密码、运营命令开通、无公开注册。以下设计阶段表格保留为决策历史；当前实现协议以 `implementationContract.md`、运行说明以 `accountService.md`、实际完成情况以 `acceptanceReport.md` 为准。

当前保守实施边界：用户专属模型令牌由运营配置；模型操作最多 30 秒复验一次身份，复验失败阻止新模型调用；失效或停用后 5 分钟内仅允许写回本会话已成功打开的文件，不允许新建。跨重启安全恢复未接入，不将内存会话描述为持久登录。旧数据不自动导入，未确认的使用数据上传不启用；管理插件、MCP/A2A 与新远程连接暂不开放。

后续已确认：沿用 Cruio 账号服务（4310），运营在 NewAPI 线下建号、创建 Key 并配置全部模型权限，然后在 Cruio 创建账号、填写 Key 完成绑定。首版后台仅登录、列表、新建和详情四页，密码下限 6 位。已取消 NewAPI 用户 ID/实例关联、在线核验、管理令牌与 Cruio 模型允许清单；不再把 NewAPI 控制台地址作为待提供项。

## 2 当前采用的约定

| 约定 | 用途 | 范围边界 |
| --- | --- | --- |
| 账号与密码登录 | 用户已确认采用最小独立账号服务 | 不扩展邮箱验证、短信或社交登录 |
| 运营协助开通 | 管理页面创建、重置、停用账号；CLI 首次授权管理员 | 不虚构联系方式，不开放公开注册 |
| Cruio 文字字标 | 使视觉稿可以评审 | 当作最终 Logo 或修改应用图标 |
| 深浅主题延续现有系统 | 减少界面割裂 | 用单张图的色调取消现有主题能力 |
| 最近项目与新增素材按账号分开 | 避免切换账号后自动混入旧内容 | 自动迁移所有旧数据给首个登录者 |
| 本地服务使用用户级 NewAPI 凭证 | 保留现有调用链，控制改造范围 | 在未验证撤销与授权能力时发放共享高权限 Key |

## 3 需要决策的项目

| 编号 | 需要确定 | 对设计的影响 | 对开发的影响 |
| --- | --- | --- | --- |
| V02 | 正式 Logo、主色、协议与帮助地址 | 字标、主题、页脚和帮助入口 | 发布素材及真实跳转目标 |
| A01（已定） | 无已有身份服务；自建最小账号密码服务 | 密码登录，联系运营 | 独立服务已实现；跨客户端重启安全存储尚未接入 |
| A02（已定） | 运营负责建号、重置与停用 | 独立管理页面，不显示公开注册入口 | 复用 4310 服务；首次管理员通过 CLI 授权 |
| A03 | NewAPI 实际用户、令牌、撤销、模型限制及媒体记录能力 | 决定模型状态及用户可见错误 | 决定身份映射粒度及直连是否可用 |
| A04 | 启动和运行中的离线规则 | 决定断网横幅、失效对话框和保存收尾 | 决定会话时限与离线授权边界 |
| A05 | 同机账户是否共享本机素材库 | 决定存量导入和素材展示范围 | 决定素材命名空间及迁移方式 |
| A06 | 使用数据字段、触发时机、开关和旧遥测出口 | 决定隐私说明及是否展示同步状态 | 决定账号队列、去重和上传接口 |
| A07 | 插件、MCP、远程连接、A2A 及开发者能力保留范围 | 决定设置分类及入口 | 决定额外鉴权面，不能只隐藏按钮 |

A03 的用户管理接口不再需要接入；实际 Key 的模型生成仍需运营联调；其他未确认能力采用前述保守边界，对应扩展功能暂不开放。余额、充值、支付、完整后台和客户 API 仍是后续候选，不因账户方案而自动纳入。
