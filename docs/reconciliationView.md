# V1 只读核对视图

`GET /api/operations/reconciliation` 为 M13 V1 提供受限只读核对数据。有效 `creditOperator` 可查询其全局 scope 或已授予的用户 scope；`admin` 不会因管理员身份获得财务读取权限。用户级过滤无授权时拒绝请求。接口不触发账本、账户、任务或结果写入。

筛选参数：

- `from`、`to`：UTC ISO 时间，默认最近 30 天，窗口最长 366 天。任务按 `generation_tasks.created_at` 筛选，外部充值、退款扣回、冲正按账本 `created_at` 筛选。
- `userId`：可选的精确用户筛选。
- `limit`、`offset`：账户页分页，默认 20 条、最多 50 条。单页用户的余额核对读取其完整历史账本，不受时间窗口或分页影响。

账户核对逐项比较 `credit_accounts.balance` 与全量账本 `SUM(amount)`，以及 `credit_accounts.reserved` 与全量账本 `SUM(reserved_delta)`。任务明细报告状态、报价、预占/实结/释放账本数量和金额、可靠交付结果记录及结果文件存在性/大小校验；标出未知任务已释放/实结、已交付未实结、失败未释放、重复或双终结记录和金额不符。最多返回窗口内 100 条任务；超过时 `tasks.truncated` 为 true，需收窄时间窗或指定用户。

外部入账部分按用户及 `topup`、`refund`、`reversal` 汇总窗口内账本净额、数量、关联账本记录和凭据记录存在性。此数据只证明应用内账本及证据关联，不证明外部付款真实性，也不构成支付、平台订单、收入或佣金报表。凭据原件、prompt、供应商密钥和自由文本内部理由不进入响应。

未发现异常只表示本次返回的范围内未发现已编码的差异，不能作为完整经营或财务对账结论。该视图不自动补账、冲正、释放预占或更改任务状态；差异应回到源模块核查处理。
