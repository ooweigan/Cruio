# Node 与工作流模型讨论记录

> 状态：方案讨论记录；尚未实现。本文记录本轮已确认的决定。剧本节点专项讨论见 `scriptNodeNotes.md`。

## Node 类型定义

- 具体 Node 类型共用一份定义契约：`type`、`displayName`、`description`、`icon`、`schemaVersion`、`dataSchema`、`defaultData`、`inputs`、`outputs`、`operations`、`allowedCanvasKinds`。
- `icon` 是前端映射的图标标识，不把 Vue 组件放进领域定义。
- `allowedCanvasKinds` 默认同时允许项目画布与工作流图；有业务限制的类型单独声明。
- 输入输出由具体类型的代码定义提供规则，不要求所有类型使用固定端口数组。Start 与 End 的端口由各自实例配置的 schema 生成。
- 暂不限制一种 Node 类型只能连接哪些下游类型。连线只需通过节点、端口存在及方向等基础结构校验。
- 可执行操作在 `operations` 中声明；每项操作声明所需的 `modelType`，不使用模型时为 `none`。打开节点时展示的 `availableModels` 按当前用户与可用模型动态取得，不是类型定义中的固定模型列表。

## Node 实例

- 公共字段为 `id`、`type`、`name`、`position`、`revision`、`data`。`data` 遵守所属类型的 `dataSchema`。
- 移动位置不增加 `revision`；内容或配置变化才增加。
- 运行状态、候选、已采用结果及历史不作为实例公共字段；连接关系也独立于节点实例。
- 从当前画布删除节点时移除其当前连线；已有运行记录、输入快照和结果继续保留。

## 执行

- 每次执行都创建独立的 Run，包括只执行一个节点的情况。Run 记录目标节点、画布版本和执行范围；实际执行的节点各有运行记录。
- 执行当前节点及必要上游时，默认复用有效的已采用上游输出；不因发起下游运行自动重跑全部上游。
- 项目画布中的交互式生成保留候选，由用户明确采用后成为下游默认输出；重新执行不自动覆盖已采用结果。
- 已发布工作流作为封装好的工具运行。调用者提供公开输入并取得声明的最终输出，无权逐个控制内部节点的配置与采用。

## 工作流 Start 与 End

- 工作流图在创建时自动生成恰好一个 Start 节点和一个 End 节点；二者不可删除，并且只允许存在于工作流图。
- Start 配置工作流的 `inputSchema`，将调用参数提供给内部节点。
- Start 的类型标识暂定为 `workflowStart`：没有输入端口，不接收内部节点的入边；输出端口由 `inputSchema` 字段生成，只能向工作流内部连出。它不选择模型，也没有生成操作。
- End 配置工作流的 `outputSchema`，从内部节点收集值并形成最终结果。一个 End 节点可以声明多个具名输出。
- End 的类型标识暂定为 `workflowEnd`：输入端口由 `outputSchema` 字段生成，接收工作流内部的值；没有面向内部的输出端口，不允许再连向内部节点。它不选择模型，也没有生成操作。
- Start 的每个输入字段与 End 的每个输出字段都可声明必填或可选。必填输入缺失时不启动运行；必填输出缺失时该 Run 不算成功，可选输出允许缺失。
- Start 的可选输入允许配置默认值。调用者未提供该字段时使用默认值，并把本次实际使用的输入值写入 Run 的输入快照。
- End 输出不配置默认值。可选输出缺失时保持缺失，必填输出缺失时不能用默认值掩盖未产出的事实。
- Start、End 的 schema 字段与普通节点输入输出端口共用同一套值类型；这项决定暂不引入“哪些节点类型允许相连”的额外限制。
- 值类型使用平台维护的受控列表，而非允许工作流作者填写任意 JSON Schema。候选包括文本、数字、布尔值、图片、视频、音频和明确的业务文档类型；集合使用 `List<T>` 表达。具体类型清单尚未定稿。
- 图片、视频、音频等媒体值以有来源类型的引用在端口间传递，并写入 Run 输入快照：素材使用 `assetId` 与固定版本；已可靠保存的生成候选使用不可变的 `resultId`，不要求先转成素材，也不需要额外的结果版本号。尚未可靠保存的临时文件不能成为可供下游读取的端口值。不把文件内容或临时 URL 当作端口值持久化。
- Start 与 End 不选择模型，也不产生独立生成任务。已发布工作流版本固定其输入输出契约。
- 这一决定取代 `CRUIO_Node_Design.md` 第 12.2 节中“工作流输入、输出只在发布配置中声明，不在画布上设置接口节点”的旧设想；正式设计文档尚未同步修订。
