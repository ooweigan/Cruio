# 剧本节点讨论记录

> 状态：已暂存；暂停剧本节点讨论。本文记录已达成的产品方向，不代表数据库或接口已经实现。

## 已确认

- 系统提供剧本库，包含私人剧本和公共剧本。公共剧本既可以由平台发布，也可以由用户发布。
- 剧本是独立的内容对象；画布中的剧本节点可以选择剧本库里的剧本。
- 用户可以在剧本库中新建剧本，也可以从剧本节点新建自定义剧本。后一入口创建的剧本同样保存到剧本库，并供该节点选择。
- 从剧本节点新建的剧本默认是私人剧本，由所有者主动发布。
- 公开的是不可变的剧本版本。用户选用公共剧本时，默认引用其固定版本；需要修改时，明确复制到自己的私人剧本库再编辑。
- 作者撤回公开后，该版本停止被新用户搜索和引用；已有节点仍可读取其固定版本。必须下架的内容走单独的处置流程。
